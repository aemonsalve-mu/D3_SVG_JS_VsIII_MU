Cargar datos para D3

28 páginas independientes: cada formato o forma de carga tiene su HTML, su archivo de ejemplo y el código para interpretarlo.

Aprender a leer archivos reales

El objetivo de estas fichas es abrir archivos externos, interpretar su formato y consultar sus datos con instrucciones sencillas. CSV, TSV, JSON y Excel forman parte del recorrido principal.

  1. CSV: leer ventas.csv con d3.csv, consultar filas y convertir una columna numérica.
  2. TSV: leer ventas.tsv con d3.tsv y comparar el separador.
  3. JSON: leer ventas.json con d3.json y acceder a sus objetos.
  4. Excel: leer directamente XLSX, XLS y ODS. D3 obtiene los bytes y SheetJS interpreta la hoja.
  5. Continuar con TXT, variantes CSV, XML, HTML, NDJSON, GeoJSON, recursos gráficos, binarios y GZIP. Cada formato tiene su archivo y su lector.

Inicia el servidor HTTP local y abre la ficha: su .js lee automáticamente el archivo de la carpeta datos. Revisa el resultado, modifica el archivo y recarga para comprobar el cambio.

Los fragmentos con texto incrustado son apoyo para interpretar el formato. Datos escritos en el código es una comparación: esa ficha no lee un archivo.

Cómo utilizar los ejemplos

  1. Abre una ficha de la lista.
  2. Abre el archivo de muestra y lee el .js que lo carga.
  3. Consulta las filas leídas y comprueba sus columnas.
  4. Modifica una instrucción en el .js y recarga el HTML.
  5. Modifica el archivo de datos, guárdalo y recarga la página. Para seleccionar un archivo del ordenador usa el laboratorio desplegable.

Selector, arrastrar y soltar y ejemplos incrustados funcionan sin servidor. La carga por URL requiere HTTP. Los archivos de texto usan UTF-8; si un archivo utiliza otra codificación, configura TextDecoder con su codificación real.

Selector de archivos: alternativas

La vía moderna para texto es await archivo.text(); para Excel o binarios, await archivo.arrayBuffer(). Las fichas usan la segunda y decodifican el texto después.

También se puede usar FileReader. Este ejemplo recibe el File obtenido de un input:

const texto = await new Promise((resolve,reject) => {
  const lector = new FileReader();
  lector.onload = () => resolve(lector.result);
  lector.onerror = () => reject(lector.error);
  lector.readAsText(archivo, "utf-8");
});
const filas = d3.csvParse(texto);

Leer texto ya pegado o definido en el código no necesita fetch: usa d3.csvParse, d3.tsvParse o JSON.parse. Leer una base de datos suele requerir una API; D3 no abre directamente una conexión SQL desde el HTML.
