d3.pointer

Devuelve [x, y] del evento en las coordenadas locales del nodo indicado. En SVG tiene en cuenta la transformación del sistema de coordenadas.

Sintaxis

d3.pointer(event, nodo)

Resultado esperado: El círculo se mueve al punto pulsado y se muestran sus coordenadas locales.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/d3pointer.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<svg id="lienzo" viewBox="0 0 500 180"><rect width="500" height="180" fill="#ccebdc"/><circle id="marca" cx="250" cy="90" r="8" fill="teal"/></svg>

JavaScript del ejemplo

const svg = d3.select("#lienzo");
// 1. Esperamos un clic en el SVG.
svg.on("click", function(event) {
  // 2. El resultado es una lista de dos números: [x, y].
  const punto = d3.pointer(event, this);
  // 3. Las posiciones 0 y 1 contienen x e y.
  d3.select("#marca").attr("cx", punto[0]).attr("cy", punto[1]);
  d3.select("#salida").text("x local: " + punto[0] + "\ny local: " + punto[1]);
});

Cómo leerlo
this es el SVG con el escuchador. event.target podría ser el rectángulo o el círculo interior y no se usa como referencia aquí.


Las coordenadas SVG no son necesariamente píxeles de pantalla. viewBox mantiene un sistema local de 500 × 180 aunque cambie el tamaño de la ventana.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Pulsa en el centro: aproximadamente 250 y 90.
2. Prueba viewBox="0 0 1000 360" y compara las coordenadas centrales.
