d3.select

Busca en todo el documento y devuelve una selección con la primera coincidencia del selector CSS. También admite un nodo DOM. No crea elementos.

Sintaxis

d3.select("selector CSS")

Resultado esperado: Ana queda verde; Sara, en negrita; Luis tiene fondo verde. La salida muestra Ana y Sara.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/d3select.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="grupo-a" class="grupo">
  <h3>Grupo A</h3>
  <p class="alumno">Ana</p>
  <div class="subgrupo">
    <p class="alumno">Luis</p>
  </div>
  <p class="alumno">Eva</p>
</div>
<div id="grupo-b" class="grupo">
  <h3>Grupo B</h3>
  <p class="alumno">Sara</p>
  <p class="alumno">Leo</p>
</div>

JavaScript del ejemplo

// 1. La clase alumno aparece cinco veces. Solo se elige la primera.
d3.select(".alumno").style("color", "teal");

// 2. El selector completo limita la búsqueda al grupo B.
// El espacio significa: un descendiente, a cualquier profundidad.
d3.select("#grupo-b .alumno").style("font-weight", "bold");

// 3. Un id identifica un elemento concreto.
const grupo = d3.select("#grupo-a");

// 4. La siguiente búsqueda empieza DENTRO del grupo A.
grupo.select(".subgrupo p").style("background", "#ccebdc");

d3.select("#salida").text("Primera alumna del documento: " + d3.select(".alumno").text() + "\nPrimera del grupo B: " + d3.select("#grupo-b .alumno").text());

Cómo leerlo
El navegador recorre el DOM en orden del documento. Primero encuentra Ana. Luis está anidado, pero también puede encontrarse con un selector descendiente.


d3.select(".alumno") busca desde document. d3.select("#grupo-b .alumno") también busca desde document, pero el selector exige que el alumno esté dentro del grupo B.


d3.select("#grupo-a").select(".alumno") hace dos pasos: selecciona el contenedor y después busca dentro de él. No busca en sus hermanos ni en sus ancestros.


No hay herencia de datos por colocar un elemento dentro de otro en HTML. d3.select no copia el dato del padre DOM. Más adelante, selection.select sí puede propagar el dato de una selección padre.


Lectura de los ejemplos: const guarda un valor o una selección con un nombre; las comillas delimitan texto. Un punto llama a un método y los paréntesis contienen sus argumentos. Al encadenar métodos, cada uno actúa sobre lo que devuelve el anterior.
Selectores CSS: p es una etiqueta; .alumno es una clase que pueden compartir varios nodos; #grupo-a es un id que debe ser único. El espacio indica descendencia y > exige un hijo directo.
Comparación de las seis búsquedas
InstrucciónBúsquedaDato del padre
d3.selectPrimera coincidencia en el documentoNo lo copia
d3.selectAllTodas las coincidencias en el documentoNo lo copia
seleccion.selectPrimer descendiente de cada nodo seleccionadoLo transmite si existe
seleccion.selectAllTodos los descendientes; un grupo por contenedorNo lo transmite
seleccion.selectChildPrimer hijo directo coincidenteLo transmite si existe
seleccion.selectChildrenTodos los hijos directos coincidentesNo lo transmite
Recorrido recomendado: d3.select · d3.selectAll · selection.select · selection.selectAll · selection.selectChild · selection.selectChildren
DOM y posición: padre e hijo son niveles consecutivos; descendiente puede estar a varios niveles; hermanos comparten padre. Estas búsquedas devuelven nodos dentro del contenedor, no sus hermanos ni sus ancestros. Los selectores no mueven los nodos.
