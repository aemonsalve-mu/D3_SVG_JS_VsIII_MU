selection.empty

Devuelve true si no hay ningún nodo en la selección y false si hay alguno. No significa que el elemento esté sin texto o sin hijos.

Sintaxis

seleccion.empty()

Resultado esperado: true, false y false.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionempty.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="caja-vacia"></div><p id="zona">Norte</p>

JavaScript del ejemplo

// 1. Este elemento no existe.
const ausente = d3.select("#no-existe").empty();
// 2. La caja existe aunque no tenga contenido.
const caja = d3.select("#caja-vacia").empty();
// 3. Este párrafo también existe.
const zona = d3.select("#zona").empty();
d3.select("#salida").text("Ausente: " + ausente + "\nCaja sin contenido: " + caja + "\nZona: " + zona);

Cómo leerlo
Una caja existente sin texto produce false: el nodo sí existe.


Escribir sobre una selección vacía no crea el nodo. Para crearlo, selecciona un padre existente y usa append.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Añade un elemento con id no-existe y recarga.
2. Prueba d3.selectAll("#demo .desconocida").empty().
