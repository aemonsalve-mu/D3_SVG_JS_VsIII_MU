selection.filter

Conserva los nodos que coinciden con un selector o cumplen una condición. No crea ni elimina elementos.

Sintaxis

seleccion.filter("selector")

Resultado esperado: Centro y Sur quedan verdes y en negrita; Norte no cambia.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionfilter.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<p class="zona">Norte</p><p class="zona destacada">Centro</p><p class="zona destacada">Sur</p>

JavaScript del ejemplo

const zonas = d3.selectAll("#demo .zona");
// 1. Un filtro por clase no necesita datos.
zonas.filter(".destacada").style("color", "teal");
// 2. Para filtrar por números, los asociamos antes.
zonas.data([40, 70, 100]);
zonas.filter(function(d) {
  return d >= 70;
}).style("font-weight", "bold");

Cómo leerlo
La función devuelve true para conservar el nodo en la selección o false para excluirlo.


Los nodos excluidos siguen en el DOM. Para retirarlos hace falta remove.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
En function(d), d es el dato del nodo. return entrega el resultado que D3 utilizará. Si aparece i, es el índice dentro del grupo y empieza en 0.
