selection.append

Añade un hijo al final de cada nodo seleccionado. Devuelve la selección de los hijos creados, que reciben el dato del padre si lo tiene.

Sintaxis

seleccion.append("etiqueta")

Resultado esperado: Norte — zona, Sur — zona y Centro — zona; Centro queda verde.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionappend.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="lista"><p>Norte</p></div>

JavaScript del ejemplo

const lista = d3.select("#lista");
// 1. El HTML ya contiene Norte. Creamos un párrafo después.
lista.append("p").text("Sur");
// 2. style se aplica al nuevo párrafo, no a la lista.
lista.append("p").text("Centro").style("color", "teal");
// 3. Creamos un hijo dentro de CADA párrafo.
lista.selectAll("p").append("span").text(" — zona");

Resultado

Norte



Cómo leerlo
select localiza; append crea. El nombre p es una etiqueta, sin signos < >.


Cada llamada añade otro nodo. Si la selección está vacía, append no tiene padre donde crear un hijo.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Cambia append("span") por append("b").
2. Añade Oeste al final y cuenta los párrafos con size().
