selection.enter

Devuelve los marcadores de datos sin nodo. append crea los elementos que faltan; enter por sí sola no dibuja.

Sintaxis

enlace.enter().append("etiqueta")

Resultado esperado: Norte — existente, Centro — nuevo y Sur — nuevo. Se crean dos párrafos.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionenter.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="lista"><p>Norte ya estaba en el HTML</p></div>

JavaScript del ejemplo

const lista = d3.select("#lista");
// 1. Hay un nodo existente y tres datos.
const enlace = lista.selectAll("p").data(["Norte", "Centro", "Sur"]);
const faltan = enlace.enter().size();
// 2. Creamos solo los dos párrafos que faltan.
enlace.enter().append("p").text(function(d) {
  return d + " — nuevo";
});
// 3. Actualizamos por separado el párrafo existente.
enlace.text(function(d) {
  return d + " — existente";
});
d3.select("#salida").text("Párrafos creados: " + faltan);

Resultado

Norte ya estaba en el HTML



Cómo leerlo
Los marcadores recuerdan el padre donde deben crearse los nodos. Por eso la búsqueda se hace desde #lista.


enter no incluye los nodos que ya existían. merge y join permiten actuar sobre nuevos y existentes.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
En function(d), d es el dato del nodo. return entrega el resultado que D3 utilizará. Si aparece i, es el índice dentro del grupo y empieza en 0.
Práctica
1. Empieza con dos párrafos en el HTML.
2. Añade Oeste al array.
