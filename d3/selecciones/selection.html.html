selection.html

Interpreta una cadena como HTML y reemplaza los hijos del nodo. Usa contenido conocido; para texto sin interpretar etiquetas usa text.

Sintaxis

seleccion.html("marcado HTML")

Resultado esperado: El primer bloque muestra 100 en negrita; el segundo muestra las etiquetas.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionhtml.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="con-html"><p>Contenido anterior</p></div><div id="con-texto"></div>

JavaScript del ejemplo

// 1. html crea un párrafo con una palabra en negrita.
d3.select("#con-html").html("<p>Ventas: <b>100</b></p>");
// 2. text muestra literalmente la misma cadena.
d3.select("#con-texto").text("<p>Ventas: <b>100</b></p>");

Cómo leerlo
Aquí html es el concepto estudiado; en las otras fichas el HTML inicial ya está en el archivo .html.


Este método está destinado a elementos HTML. Para SVG escribe el marcado en el HTML o crea figuras con append.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Cambia b por em.
2. Comprueba que Contenido anterior desaparece.
Predice el resultado antes de editar el .js. Recarga la página para volver a partir del HTML inicial.
