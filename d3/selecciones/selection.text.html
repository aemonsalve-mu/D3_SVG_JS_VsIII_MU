selection.text

Escribe texto literal y reemplaza los hijos del nodo. Sin argumentos lee el texto del primer nodo seleccionado.

Sintaxis

seleccion.text("texto")

Resultado esperado: Se ven literalmente <b>Ventas</b> e Informe nuevo, sin el antiguo b.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectiontext.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<p id="literal">Texto inicial</p><p id="reemplazo">Informe <b>antiguo</b></p>

JavaScript del ejemplo

// 1. Las etiquetas se muestran como texto: no crean negrita.
d3.select("#literal").text("<b>Ventas</b>");
// 2. El b anterior desaparece al reemplazar el contenido del padre.
d3.select("#reemplazo").text("Informe nuevo");
// 3. Sin argumentos, text lee.
d3.select("#salida").text(d3.select("#reemplazo").text());

Resultado

Texto inicial

Informe antiguo



Cómo leerlo
text no interpreta HTML. Es la opción habitual para mostrar nombres o valores.


Si solo quieres cambiar el b, selecciónalo a él: text sobre el padre elimina sus hijos.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Cambia solo el texto de b seleccionándolo desde su padre.
2. Compara con selection.html.
