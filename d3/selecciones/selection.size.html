UN ARCHIVO · UN CONCEPTO

selection.size

Cuenta los nodos no nulos de la selección. Cuenta elementos, no datos ni hijos ni coincidencias futuras.

Sintaxis

seleccion.size()

Resultado esperado: Cuatro zonas visibles. Los contadores son 3, 3 y 4.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionsize.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="lista"><p class="zona">Norte</p><p class="zona">Centro</p><p class="zona">Sur</p></div>

JavaScript del ejemplo

const zonas = d3.selectAll("#lista .zona");
const antes = zonas.size();
// 1. Añadimos un nodo al DOM.
d3.select("#lista").append("p").attr("class", "zona").text("Oeste");
// 2. La selección guardada mantiene sus nodos originales.
const guardada = zonas.size();
// 3. Una nueva búsqueda sí encuentra los cuatro.
const actual = d3.selectAll("#lista .zona").size();
d3.select("#salida").text("Antes: " + antes + "\nSelección guardada: " + guardada + "\nNueva selección: " + actual);

Cómo leerlo
Una selección no se actualiza automáticamente al cambiar el DOM.


d3.select("#lista").size() devuelve 1: cuenta el contenedor, no sus párrafos.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Cuenta con select en lugar de selectAll.
2. Retira una zona y compara una selección guardada con una nueva.
