selection.data

Empareja valores y nodos por grupo. Sin clave usa posiciones: primer dato con primer nodo. Devuelve la selección de actualización; no crea ni elimina nodos.

Sintaxis

seleccion.data([dato1, dato2, dato3])

Resultado esperado: Venta: 40, Venta: 70 y Venta: 100. Contadores 3, 1 y 0. El dato 55 no tiene párrafo.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectiondata.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="lista"><p>Texto A</p><p>Texto B</p><p>Texto C</p></div>

JavaScript del ejemplo

const parrafos = d3.select("#lista").selectAll("p");
// 1. data asocia números; todavía no cambia los textos.
const enlace = parrafos.data([40, 70, 100, 55]);
// 2. Tenemos tres nodos, pero cuatro datos.
const actualizados = enlace.size();
const nuevos = enlace.enter().size();
const sobrantes = enlace.exit().size();
// 3. text muestra los datos que ya tienen un nodo.
enlace.text(function(d) {
  return "Venta: " + d;
});
d3.select("#salida").text("Con nodo: " + actualizados + "\nSin nodo todavía: " + nuevos + "\nNodos sobrantes: " + sobrantes);

Cómo leerlo
Un array es una lista entre corchetes. Aquí no necesitamos objetos ni funciones flecha.


enter representa datos sin nodo; exit, nodos sin correspondencia en los datos nuevos.


Con varios contenedores, selectAll crea grupos y data empareja por grupo. Una clave, explicada en order, permite emparejar por identidad.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
En function(d), d es el dato del nodo. return entrega el resultado que D3 utilizará. Si aparece i, es el índice dentro del grupo y empieza en 0.
Práctica
1. Usa [40, 70]: hay dos nodos de actualización y uno de salida, aunque los tres sigan visibles.
2. Comenta text y comprueba que data no cambia las palabras del HTML.
