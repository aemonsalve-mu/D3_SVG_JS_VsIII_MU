selection.on

Registra una función para un evento. En D3 7 recibe event y el dato d; con function, this es el nodo que tiene el escuchador.

Sintaxis

seleccion.on("click", function(event, d) { ... })

Resultado esperado: Al pulsar un botón se muestra su zona y click; ese botón queda naranja.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionon.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<button class="zona">Norte</button><button class="zona">Sur</button>

JavaScript del ejemplo

// 1. Un dato por botón.
const botones = d3.selectAll("#demo .zona").data(["Norte", "Sur"]);
// 2. Esta función espera un clic; no se ejecuta al registrarla.
botones.on("click.detalle", function(event, d) {
  d3.select("#salida").text("Zona seleccionada: " + d + "\nEvento: " + event.type);
  d3.select(this).style("background", "orange");
});
// 3. Para retirar el escuchador, descomenta la línea siguiente.
// botones.on(".detalle", null);

Resultado



Cómo leerlo
event contiene información del clic; d es el dato del botón. No son el mismo argumento.


El sufijo .detalle es un nombre de escuchador D3, no una clase CSS. Permite retirarlo sin quitar otros.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Descomenta la última línea.
2. Prueba mouseenter.detalle en lugar de click.detalle.
