selection.style

Escribe una propiedad CSS en los nodos seleccionados. Sin el segundo argumento lee el estilo del primer nodo; null retira la declaración en línea.

Sintaxis

seleccion.style("propiedad CSS", "valor")

Resultado esperado: Las tres zonas tienen texto verde y fondo verde claro; solo Norte está en negrita.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionstyle.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<p class="zona">Norte</p><p class="zona">Centro</p><p class="zona">Sur</p>

JavaScript del ejemplo

// 1. Una instrucción cambia los tres párrafos.
d3.selectAll("#demo .zona").style("color", "teal");
// 2. select cambia solo el primero.
d3.select("#demo .zona").style("font-weight", "bold");
// 3. background y font-weight son propiedades CSS.
d3.selectAll("#demo .zona").style("background", "#ccebdc");

Centro

Sur



Cómo leerlo
Las propiedades CSS con guion se escriben entre comillas: "font-weight".


Heredar un color CSS del padre no significa recibir un dato de D3.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Sustituye selectAll por select en la primera instrucción.
2. Prueba style("color", null).
