UN ARCHIVO · UN CONCEPTO

selection.selectChildren

Selecciona todos los hijos directos coincidentes de cada contenedor. No incluye nietos y no copia automáticamente los datos del padre.

Sintaxis

const grupo = d3.select("#grupo-a");
const directos = grupo.selectChildren("p");

grupo contiene el contenedor A; directos recibe la selección de sus hijos directos con etiqueta p. Ambos nombres son variables elegidas para el ejemplo.

Resultado esperado: Ana y Eva quedan verdes. Los contadores son 2, 3 y 4: h3, dos párrafos y el div del subgrupo son hijos elemento.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionselectchildren.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="grupo-a" class="grupo">
  <h3>Grupo A</h3>
  <p class="alumno">Ana</p>
  <div class="subgrupo">
    <p class="alumno">Luis</p>
  </div>
  <p class="alumno">Eva</p>
</div>
<div id="grupo-b" class="grupo">
  <h3>Grupo B</h3>
  <p class="alumno">Sara</p>
  <p class="alumno">Leo</p>
</div>

JavaScript del ejemplo

const grupo = d3.select("#grupo-a");
// 1. Ana y Eva son hijos directos. Luis no lo es.
const directos = grupo.selectChildren("p");
directos.style("color", "teal");
// 2. Una búsqueda de descendientes sí incluye Luis.
const todos = grupo.selectAll("p");
// 3. Sin selector se eligen todos los hijos que sean elementos.
const elementos = grupo.selectChildren();
d3.select("#salida").text("Hijos directos p: " + directos.size() + "\nTodos los descendientes p: " + todos.size() + "\nHijos elemento de A: " + elementos.size());

Cómo leerlo
selectChildren("p") exige un solo nivel de parentesco. selectAll("p") admite cualquier profundidad.


selectChildren() sin argumento también incluye h3 y div. Los espacios y saltos de línea no se cuentan como elementos.


Como selectAll, crea grupos por contenedor y conserva los datos propios de los hijos. La versión singular selectChild sí propaga el dato del padre cuando existe.


Lectura de los ejemplos: const guarda un valor o una selección con un nombre; las comillas delimitan texto. Un punto llama a un método y los paréntesis contienen sus argumentos. Al encadenar métodos, cada uno actúa sobre lo que devuelve el anterior.
Selectores CSS: p es una etiqueta; .alumno es una clase que pueden compartir varios nodos; #grupo-a es un id que debe ser único. El espacio indica descendencia y > exige un hijo directo.
Recorrido recomendado: d3.select · d3.selectAll · selection.select · selection.selectAll · selection.selectChild · selection.selectChildren
DOM y posición: padre e hijo son niveles consecutivos; descendiente puede estar a varios niveles; hermanos comparten padre. Estas búsquedas devuelven nodos dentro del contenedor, no sus hermanos ni sus ancestros. Los selectores no mueven los nodos.
Práctica
1. Añade un párrafo dentro del subgrupo: solo debe aumentar el contador de descendientes.
2. Añade un párrafo directamente al grupo A: deben aumentar ambos contadores de párrafos.
