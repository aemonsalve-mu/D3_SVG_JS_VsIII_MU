UN ARCHIVO · UN CONCEPTO

selection.nodes

Devuelve un array con todos los nodos DOM de la selección, aplanando sus grupos. Para contar sin obtener el array usa size().

Sintaxis

seleccion.nodes()

Resultado esperado: La salida indica 3, Norte y Sur. Centro queda verde.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionnodes.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<p class="zona">Norte</p><p class="zona">Centro</p><p class="zona">Sur</p>

JavaScript del ejemplo

const zonas = d3.selectAll("#demo .zona");
// 1. nodes devuelve un array; sus posiciones empiezan en 0.
const nodos = zonas.nodes();
// 2. Leemos posiciones sin bucles ni map.
d3.select("#salida").text("Cantidad: " + nodos.length + "\nPrimero: " + nodos[0].textContent + "\nTercero: " + nodos[2].textContent);
// 3. La posición 1 contiene el segundo nodo DOM.
d3.select(nodos[1]).style("color", "teal");

Resultado

Norte

Centro

Sur



Cómo leerlo
Los corchetes acceden a una posición del array. nodos[1] es el segundo nodo.


nodes devuelve un array; node devuelve un único nodo o null.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Selecciona nodos[2].
2. Añade Oeste al HTML y consulta nodos.length.
