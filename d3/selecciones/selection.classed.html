selection.classed

Añade o quita una clase sin reemplazar las demás. Con un argumento comprueba si el primer nodo tiene la clase.

Sintaxis

seleccion.classed("clase", true)

Resultado esperado: Norte tiene el borde lateral de notice; Sur no. La salida es true.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionclassed.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<p id="norte" class="zona">Norte</p><p id="sur" class="zona">Sur</p>

JavaScript del ejemplo

// 1. notice ya tiene un estilo en la hoja común.
d3.selectAll("#demo .zona").classed("notice", true);
// 2. Quitamos notice solo de Sur; zona se conserva.
d3.select("#sur").classed("notice", false);
const tieneClase = d3.select("#norte").classed("notice");
d3.select("#salida").text("¿Norte tiene notice? " + tieneClase);

Resultado

Norte

Sur



Cómo leerlo
true añade la clase; false la quita. En classed el nombre se escribe sin punto.


Para seleccionar por clase sí se escribe el punto: d3.select(".notice").


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Cambia false por true para Sur.
2. Comprueba que ambos mantienen la clase zona.
Predice el resultado antes de editar el .js. Recarga la página para volver a partir del HTML inicial.
