selection.select

Parte de una selección que ya has creado y busca dentro de cada uno de sus elementos. De cada contenedor elige solo el primer descendiente que coincide con el selector CSS.

Sintaxis

const grupos = d3.selectAll("#demo .grupo");
const primeros = grupos.select(".alumno");

Cómo se lee: primero guardamos los dos contenedores en una variable llamada grupos. Después, grupos.select(".alumno") busca el primer alumno dentro de cada contenedor. Guardamos el resultado en primeros.

grupos y primeros son nombres que elegimos nosotros; no son comandos de D3. select sí es el nombre del método y se escribe así, en inglés. En la documentación, selection.select significa «llamar a select sobre una selección»; D3 no crea automáticamente una variable llamada selection.

Resultado esperado: Dos alumnos elegidos: Ana y Sara quedan verdes. Luis tiene fondo verde. En la ampliación, el dato de Ana pasa de «Dato propio de Ana» a «Dato del grupo A»; su nombre visible no cambia.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionselect.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="grupo-a" class="grupo">
  <h3>Grupo A</h3>
  <p class="alumno">Ana</p>
  <div class="subgrupo">
    <p class="alumno">Luis</p>
  </div>
  <p class="alumno">Eva</p>
</div>
<div id="grupo-b" class="grupo">
  <h3>Grupo B</h3>
  <p class="alumno">Sara</p>
  <p class="alumno">Leo</p>
</div>

JavaScript del ejemplo

// 1. d3.selectAll busca los dos contenedores en el documento.
const grupos = d3.selectAll("#demo .grupo");

// 2. select busca DENTRO de cada contenedor: Ana y Sara.
const primeros = grupos.select(".alumno");
primeros.style("color", "teal");

// 3. Una búsqueda también puede llegar a un descendiente anidado.
const grupoA = d3.select("#grupo-a");
grupoA.select(".subgrupo p").style("background", "#ccebdc");

// 4. Ampliación: datum guarda un dato, sin cambiar el texto HTML.
// Lee primero la ficha datum si aún no conoces este método.
grupoA.datum("Dato del grupo A");
d3.select("#grupo-a > p").datum("Dato propio de Ana");
const antes = d3.select("#grupo-a > p").datum();

// 5. select desde grupoA transmite su dato a la primera alumna.
grupoA.select(".alumno");
const despues = d3.select("#grupo-a > p").datum();

d3.select("#salida").text(
  "Alumnos elegidos: " + primeros.size() + "\n" +
  "Dato de Ana antes: " + antes + "\n" +
  "Dato de Ana después: " + despues
);

Cómo leerlo
Documento frente a contenedor. d3.select(".alumno") empieza en el documento y encuentra Ana. grupos.select(".alumno") empieza en cada contenedor ya seleccionado: encuentra Ana en A y Sara en B.


Uno por contenedor. select no significa siempre «un único nodo en toda la página». Si partes de dos contenedores, puede devolver dos nodos, uno por cada contenedor donde encuentre una coincidencia.


Descendiente no significa hijo directo. Luis está dentro del div del subgrupo. grupoA.select(".subgrupo p") puede encontrarlo porque select busca también a varios niveles. Para exigir un hijo directo utiliza selectChild.


La posición no cambia. Buscar un alumno no lo mueve de contenedor ni modifica sus hermanos. Si un contenedor no tiene coincidencia, no aporta ningún nodo a ese resultado.


La transmisión del dato es un paso posterior. Solo si el contenedor tiene un dato enlazado, select lo asigna al descendiente encontrado y puede reemplazar su dato anterior. El parentesco HTML por sí solo no transmite datos. Estudia datum antes de las últimas líneas del ejemplo. La herencia de colores CSS es otro mecanismo.


Lectura de los ejemplos: const guarda un valor o una selección con un nombre; las comillas delimitan texto. Un punto llama a un método y los paréntesis contienen sus argumentos. Al encadenar métodos, cada uno actúa sobre lo que devuelve el anterior.
Selectores CSS: p es una etiqueta; .alumno es una clase que pueden compartir varios nodos; #grupo-a es un id que debe ser único. El espacio indica descendencia y > exige un hijo directo.
Dato: datum(valor) asocia un dato a un nodo y datum() lo lee. data([valor1, valor2]) reparte valores entre nodos. Estas operaciones no escriben texto por sí solas. Puedes revisar datum y data por separado.
Recorrido recomendado: d3.select · d3.selectAll · selection.select · selection.selectAll · selection.selectChild · selection.selectChildren
DOM y posición: padre e hijo son niveles consecutivos; descendiente puede estar a varios niveles; hermanos comparten padre. Estas búsquedas devuelven nodos dentro del contenedor, no sus hermanos ni sus ancestros. Los selectores no mueven los nodos.

3. Cambia .subgrupo p por .alumno en la tercera parte: ¿qué párrafo encuentra ahora dentro de A?
