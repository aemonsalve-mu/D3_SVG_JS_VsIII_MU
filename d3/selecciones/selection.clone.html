UN ARCHIVO · UN CONCEPTO

selection.clone

Copia cada nodo y lo inserta después del original. true incluye los hijos; false copia solo el elemento.

Sintaxis

seleccion.clone(true)

Resultado esperado: Dos informes Norte con negrita; después del informe Sur aparece Copia sin hijos originales.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionclone.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="profundo"><p class="informe">Informe <b>Norte</b></p></div><div id="superficial"><p class="informe">Informe <b>Sur</b></p></div>

JavaScript del ejemplo

// 1. Copia el párrafo y su contenido.
d3.select("#profundo p").clone(true);
// 2. Copia el párrafo sin texto ni b.
const copia = d3.select("#superficial p").clone(false);
// 3. Escribimos algo para reconocer la copia vacía.
copia.text("Copia sin hijos originales");

Resultado

Informe Norte

Informe Sur



Cómo leerlo
El texto también es un nodo hijo; clone(false) no lo copia.


Evita duplicar id. Aquí los párrafos usan clases. Los escuchadores registrados con on no se copian automáticamente.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Elimina la última instrucción y observa la copia vacía en el inspector.
2. Cambia false por true.
Predice el resultado antes de editar el .js. Recarga la página para volver a partir del HTML inicial.
