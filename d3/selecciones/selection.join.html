selection.join

Después de data crea los nodos que faltan, conserva los emparejados, retira los sobrantes y devuelve la selección resultante.

Sintaxis

seleccion.data(datos).join("etiqueta")

Resultado esperado: Al terminar quedan Norte y Sur. Los contadores son 3 y 2.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionjoin.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="lista"><p>Texto anterior</p></div>

JavaScript del ejemplo

const lista = d3.select("#lista");
// 1. Pasamos de uno a tres párrafos: se crean dos.
lista.selectAll("p").data(["Norte", "Centro", "Sur"]).join("p").text(function(d) {
  return d;
});
const primeraCantidad = lista.selectAll("p").size();
// 2. Pasamos de tres a dos: se retira un nodo.
lista.selectAll("p").data(["Norte", "Sur"]).join("p").text(function(d) {
  return d;
});
d3.select("#salida").text("Primera actualización: " + primeraCantidad + "\nSegunda actualización: " + lista.selectAll("p").size());

Cómo leerlo
Las instrucciones se ejecutan en orden al cargar; se ve el estado final. El contador registra el intermedio.


Sin clave, el segundo nodo se reutiliza para Sur y se retira el tercero. D3 no identifica nodos por el texto.


join resume el patrón de enter, actualización y exit; no acumula párrafos en cada actualización.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
En function(d), d es el dato del nodo. return entrega el resultado que D3 utilizará. Si aparece i, es el índice dentro del grupo y empieza en 0.
Práctica
1. Añade una tercera actualización con un dato.
2. Compara con enter y exit.
