selection.selectAll

Busca todos los descendientes coincidentes dentro de cada nodo seleccionado. Crea un grupo de selección por contenedor y no transmite automáticamente el dato del padre a sus descendientes.

Sintaxis

const grupos = d3.selectAll("#demo .grupo");
const alumnos = grupos.selectAll(".alumno");

grupos es una variable creada con d3.selectAll. Después, grupos.selectAll busca todos los alumnos dentro de cada contenedor de esa selección.

Resultado esperado: Los cinco alumnos quedan verdes. Los índices son 0, 1, 2 en A y 0, 1 en B. Antes de asignar los nombres, Ana conserva su dato propio.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionselectall.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

JavaScript del ejemplo

// 1. Asociamos un dato distinto a cada contenedor.
const grupos = d3.selectAll("#demo .grupo");
grupos.data(["Norte", "Sur"]);
// 2. Ana tiene un dato propio antes de seleccionar los descendientes.
d3.select("#grupo-a > p").datum("Dato propio de Ana");
// 3. Se eligen tres alumnos de A y dos de B, sin copiar Norte ni Sur.
const alumnos = grupos.selectAll(".alumno");
alumnos.style("color", "teal");
const conservado = alumnos.datum();

// 4. Asignamos los datos de cada grupo de manera explícita.
d3.select("#grupo-a").selectAll("p").data(["Ana", "Luis", "Eva"]);
d3.select("#grupo-b").selectAll("p").data(["Sara", "Leo"]);
// 5. i empieza en 0 dentro de CADA grupo de selección.
alumnos.text(function(d, i) {
  return d + " (índice " + i + ")";
});

d3.select("#salida").text("Alumnos: " + alumnos.size() + "\nDato conservado antes de data: " + conservado);

Cómo leerlo
Las búsquedas quedan dentro de cada contenedor. Los nodos no cambian de padre en el DOM: los grupos de selección son una organización interna de D3.


selectAll no copia Norte ni Sur a los párrafos. Los datos que ya tenían los hijos se conservan hasta que se cambien explícitamente.


data([...]) asigna valores por orden a los nodos de cada grupo de selección. Aquí hacemos una asignación sencilla por contenedor, sin arrays de objetos ni funciones anidadas.


En function(d, i), d es el dato del nodo e i su índice dentro del grupo. return indica el texto que D3 debe escribir. No necesitamos funciones flecha.


Una selección global y una agrupada pueden contener el mismo número de nodos. Lo que cambia es cómo se reparten en grupos y dónde empieza otra vez el índice i.


Lectura de los ejemplos: const guarda un valor o una selección con un nombre; las comillas delimitan texto. Un punto llama a un método y los paréntesis contienen sus argumentos. Al encadenar métodos, cada uno actúa sobre lo que devuelve el anterior.
Selectores CSS: p es una etiqueta; .alumno es una clase que pueden compartir varios nodos; #grupo-a es un id que debe ser único. El espacio indica descendencia y > exige un hijo directo.
Dato: datum(valor) asocia un dato a un nodo y datum() lo lee. data([valor1, valor2]) reparte valores entre nodos. Estas operaciones no escriben texto por sí solas. Puedes revisar datum y data por separado.
Recorrido recomendado: d3.select · d3.selectAll · selection.select · selection.selectAll · selection.selectChild · selection.selectChildren
DOM y posición: padre e hijo son niveles consecutivos; descendiente puede estar a varios niveles; hermanos comparten padre. Estas búsquedas devuelven nodos dentro del contenedor, no sus hermanos ni sus ancestros. Los selectores no mueven los nodos.
En function(d), d es el dato del nodo. return entrega el resultado que D3 utilizará. Si aparece i, es el índice dentro del grupo y empieza en 0.
Práctica
1. Cambia grupos.selectAll por grupos.select y predice cuántos nombres se actualizan.
2. Asigna ["A", "B", "C"] al grupo A y observa qué texto cambia.
3. Compara los índices con d3.selectAll("#demo .alumno").text(function(d, i) { return d + " / " + i; });: ahora forman un solo grupo, del 0 al 4.
