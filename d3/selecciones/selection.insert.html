selection.insert

Crea un hijo antes del primer nodo que coincide con el segundo selector. La referencia debe ser un hijo directo del padre donde se inserta.

Sintaxis

seleccion.insert("etiqueta", "referencia")

Resultado esperado: Norte, Centro, Sur y Oeste, en ese orden.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectioninsert.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="lista"><p id="sur">Sur</p></div>

JavaScript del ejemplo

const lista = d3.select("#lista");
// 1. Norte se inserta antes de Sur.
lista.insert("p", "#sur").text("Norte");
// 2. Centro también se inserta antes de Sur.
lista.insert("p", "#sur").text("Centro");
// 3. Sin referencia se añade al final.
lista.insert("p").text("Oeste");

Resultado

Sur



Cómo leerlo
El segundo selector identifica una referencia; no reemplaza ese nodo.


Si no encuentra referencia, añade al final. Evita referencias anidadas que no sean hijos directos.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Compara insert("p", "#sur") con append("p").
2. Inserta una zona antes del primer párrafo.
