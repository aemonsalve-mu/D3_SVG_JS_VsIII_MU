selection.merge

Combina selecciones compatibles por sus posiciones, sin concatenarlas. En el patrón de datos reúne nodos nuevos y existentes.

Sintaxis

nuevos.merge(existentes)

Resultado esperado: Norte y Sur verdes: uno ya existía y otro se crea.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionmerge.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="lista"><p>Texto anterior</p></div>

JavaScript del ejemplo

const lista = d3.select("#lista");
// 1. update contiene el nodo existente en la primera posición.
const update = lista.selectAll("p").data(["Norte", "Sur"]);
// 2. enter crea el nodo que falta en la segunda posición.
const enter = update.enter().append("p");
// 3. Aplicamos el mismo texto y estilo a los dos.
enter.merge(update).text(function(d) {
  return d;
}).style("color", "teal");

Cómo leerlo
update significa actualización; enter, entrada. Son nombres de variables.


merge conserva posiciones y grupos; no es una unión general de arrays o selecciones arbitrarias.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
En function(d), d es el dato del nodo. return entrega el resultado que D3 utilizará. Si aparece i, es el índice dentro del grupo y empieza en 0.
