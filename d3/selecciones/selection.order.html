selection.order

Mueve los nodos hermanos del DOM para que sigan el orden de la selección. No calcula una ordenación por valores.

Sintaxis

seleccion.order()

Resultado esperado: Sur, Norte y Centro. Se reutilizan los mismos nodos.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionorder.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="lista"><p>Norte</p><p>Centro</p><p>Sur</p></div>

JavaScript del ejemplo

const lista = d3.select("#lista");
lista.selectAll("p").data(["Norte", "Centro", "Sur"]);
// 1. La clave identifica cada nodo por su dato, no por su posición.
function clave(d) {
  return d;
}
// 2. El nuevo enlace devuelve la selección en el orden de los datos.
const nuevoOrden = lista.selectAll("p").data(["Sur", "Norte", "Centro"], clave);
// 3. El DOM no cambia de orden hasta ejecutar order.
nuevoOrden.order();

Resultado

Norte

Centro

Sur



Cómo leerlo
Cada nombre es distinto y actúa como identificador estable. Sin clave, data emparejaría por posición.


order sigue el orden de la selección; sort calcula uno con un comparador.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Comenta order y observa el orden original en el DOM.
2. Usa ["Centro", "Sur", "Norte"].
Predice el resultado antes de editar el .js. Recarga la página para volver a partir del HTML inicial.
