selection.dispatch

Envía un evento DOM a los nodos seleccionados. Puede activar escuchadores registrados con on sin un clic físico.

Sintaxis

seleccion.dispatch("tipo", parametros)

Resultado esperado: Al cargar: Revisado por analítica. Al pulsar: Nueva revisión.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectiondispatch.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<button id="informe">Informe</button>

JavaScript del ejemplo

const boton = d3.select("#informe");
// 1. Escuchamos un evento propio llamado revision.
boton.on("revision", function(event) {
  d3.select("#salida").text("Detalle recibido: " + event.detail);
});
// 2. Enviamos el evento con información adicional.
boton.dispatch("revision", {detail: "Revisado por analítica"});
// 3. Un clic envía otra revisión.
boton.on("click", function() {
  boton.dispatch("revision", {detail: "Nueva revisión"});
});

Resultado



Cómo leerlo
{detail: ...} es un objeto sencillo con información del evento; no cambia el dato d del nodo.


Por defecto no asciende por los padres DOM. bubbles: true permite esa propagación; es distinta de heredar datos.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Cambia el texto de detail.
2. Comenta el primer dispatch para que solo se ejecute al pulsar.
