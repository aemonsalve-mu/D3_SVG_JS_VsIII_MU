selection.property

Lee o modifica una propiedad DOM como checked o value. Es el valor actual que maneja el control.

Sintaxis

seleccion.property("nombre", valor)

Resultado esperado: La casilla queda marcada y el campo muestra Sur. La salida indica true y Sur.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionproperty.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<label><input id="activo" type="checkbox"> Zona activa</label><label for="zona">Nombre de zona</label><input id="zona" value="Norte">

JavaScript del ejemplo

// 1. Marcamos la casilla con un valor booleano.
d3.select("#activo").property("checked", true);
// 2. Cambiamos el valor actual del campo.
d3.select("#zona").property("value", "Sur");
// 3. Sin segundo argumento se lee la propiedad.
const marcado = d3.select("#activo").property("checked");
const nombre = d3.select("#zona").property("value");
d3.select("#salida").text("Marcado: " + marcado + "\nValor actual: " + nombre);

Resultado



Cómo leerlo
Usa true o false, no las cadenas "true" o "false", para checked.


El atributo HTML value describe el valor inicial; la propiedad value contiene el actual. Para leer lo escrito por una persona, usa property("value").


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Cambia checked a false.
2. Escribe otro texto y consulta property("value") en la consola.
