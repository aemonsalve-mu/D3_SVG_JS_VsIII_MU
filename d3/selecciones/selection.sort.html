selection.sort

Devuelve una selección ordenada por un comparador de datos y mueve los nodos del DOM para seguir ese orden.

Sintaxis

seleccion.sort(comparador)

Resultado esperado: Los párrafos muestran 40, 70 y 100.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionsort.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<p class="venta">40</p><p class="venta">100</p><p class="venta">70</p>

JavaScript del ejemplo

const ventas = d3.selectAll("#demo .venta");
// 1. sort compara datos; no lee el texto HTML automáticamente.
ventas.data([40, 100, 70]);
// 2. D3 incluye un comparador de menor a mayor.
ventas.sort(d3.ascending);
// 3. Para invertir el orden, prueba d3.descending.

Resultado

40

100

70



Cómo leerlo
ascending ordena de menor a mayor; descending, de mayor a menor.


Si necesitas usar la selección ordenada después, guarda el valor devuelto por sort.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Prueba d3.descending.
2. Cambia los números del HTML y de data de forma coherente.
