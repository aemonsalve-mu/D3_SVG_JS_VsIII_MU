selection.datum

Asocia un dato a cada nodo sin calcular entradas ni salidas. Sin argumentos lee el dato del primer nodo; null lo elimina.

Sintaxis

seleccion.datum(dato)

Resultado esperado: La salida indica 40. Los párrafos muestran Venta: 40 y Venta: 70.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectiondatum.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<p id="norte">Texto inicial de Norte</p><p id="sur">Texto inicial de Sur</p>

JavaScript del ejemplo

// 1. Guardar un dato NO cambia el texto que había.
d3.select("#norte").datum(40);
d3.select("#sur").datum(70);
// 2. Leemos el dato de Norte.
const venta = d3.select("#norte").datum();
d3.select("#salida").text("Dato de Norte: " + venta);
// 3. Ahora escribimos texto a partir de cada dato.
d3.selectAll("#demo p").text(function(d) {
  return "Venta: " + d;
});

Resultado

Texto inicial de Norte

Texto inicial de Sur



Cómo leerlo
Un dato D3 no es el texto ni un atributo HTML del nodo.


datum([40, 70]) guarda el array completo en cada nodo; data([40, 70]) reparte un valor por nodo del grupo.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
En function(d), d es el dato del nodo. return entrega el resultado que D3 utilizará. Si aparece i, es el índice dentro del grupo y empieza en 0.
Práctica
1. Comenta la última llamada a text: guardar datos no modifica el texto inicial.
2. Asigna datum(100) a los dos párrafos.
Predice el resultado antes de editar el .js. Recarga la página para volver a partir del HTML inicial.
