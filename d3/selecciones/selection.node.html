selection.node

Devuelve el primer nodo DOM de la selección o null si está vacía. El resultado no es una selección D3.

Sintaxis

seleccion.node()

Resultado esperado: La salida muestra P y Norte. Solo Norte queda verde.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionnode.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<p class="zona">Norte</p><p class="zona">Sur</p>

JavaScript del ejemplo

const zonas = d3.selectAll("#demo .zona");
// 1. node devuelve solo el primer párrafo DOM.
const nodo = zonas.node();
// 2. tagName y textContent son propiedades del DOM.
d3.select("#salida").text("Etiqueta: " + nodo.tagName + "\nTexto: " + nodo.textContent);
// 3. Para usar métodos D3, seleccionamos ese nodo.
d3.select(nodo).style("color", "teal");

Resultado

Norte

Sur



Cómo leerlo
nodo.textContent pertenece al DOM; seleccion.text() pertenece a D3.


No consultes propiedades de null. Comprueba empty() si el selector puede no encontrar un nodo.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Cambia el selector para elegir Sur.
2. Comprueba que d3.select("#ausente").node() devuelve null.
