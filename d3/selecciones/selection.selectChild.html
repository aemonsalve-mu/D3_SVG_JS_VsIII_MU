selection.selectChild

Selecciona el primer hijo directo coincidente de cada nodo seleccionado. No busca nietos. Si el padre tiene un dato enlazado, lo transmite al hijo seleccionado.

Sintaxis

const grupo = d3.select("#grupo-a");
grupo.selectChild("p");

grupo es la selección del contenedor A. selectChild busca únicamente entre sus hijos directos; p indica la etiqueta que debe coincidir.

Resultado esperado: Ana queda verde, Luis con fondo verde y Sara en negrita. La salida muestra Ana.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionselectchild.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<div id="grupo-a" class="grupo">
  <h3>Grupo A</h3>
  <p class="alumno">Ana</p>
  <div class="subgrupo">
    <p class="alumno">Luis</p>
  </div>
  <p class="alumno">Eva</p>
</div>
<div id="grupo-b" class="grupo">
  <h3>Grupo B</h3>
  <p class="alumno">Sara</p>
  <p class="alumno">Leo</p>
</div>

JavaScript del ejemplo

const grupo = d3.select("#grupo-a");
// 1. select puede llegar hasta el párrafo anidado de Luis.
grupo.select(".subgrupo p").style("background", "#ccebdc");
// 2. selectChild solo considera los hijos directos: Ana es la primera p.
grupo.selectChild("p").style("color", "teal");
// 3. En el grupo B se elige Sara, aunque Leo también coincide.
d3.select("#grupo-b").selectChild(".alumno").style("font-weight", "bold");
d3.select("#salida").text("Primer hijo p de A: " + grupo.selectChild("p").text());

Cómo leerlo
El h3 también es hijo directo, pero no coincide con p. Por eso selectChild("p") elige Ana.


Sin selector, selectChild() elige el primer hijo que sea un elemento: aquí sería h3. No cuenta los saltos de línea como elementos.


Para todos los hijos directos se utiliza selectChildren. Para buscar a cualquier profundidad se utiliza select o selectAll.


Lectura de los ejemplos: const guarda un valor o una selección con un nombre; las comillas delimitan texto. Un punto llama a un método y los paréntesis contienen sus argumentos. Al encadenar métodos, cada uno actúa sobre lo que devuelve el anterior.
Selectores CSS: p es una etiqueta; .alumno es una clase que pueden compartir varios nodos; #grupo-a es un id que debe ser único. El espacio indica descendencia y > exige un hijo directo.
Recorrido recomendado: d3.select · d3.selectAll · selection.select · selection.selectAll · selection.selectChild · selection.selectChildren
DOM y posición: padre e hijo son niveles consecutivos; descendiente puede estar a varios niveles; hermanos comparten padre. Estas búsquedas devuelven nodos dentro del contenedor, no sus hermanos ni sus ancestros. Los selectores no mueven los nodos.
Práctica
1. Prueba selectChild() sin argumento y comprueba qué etiqueta cambia.
2. Mueve todo el div del subgrupo antes del párrafo de Ana: selectChild("p") debe seguir encontrando Ana.
