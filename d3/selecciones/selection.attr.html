selection.attr

Escribe un atributo en todos los nodos seleccionados; con un argumento lee el atributo del primer nodo. null elimina el atributo.

Sintaxis

seleccion.attr("nombre", valor)

Resultado esperado: Los dos radios pasan de 20 a 30. Solo el primer círculo queda naranja.

Ejemplo paso a paso

El HTML ya contiene los elementos iniciales. El archivo js/selectionattr.js se carga al final de la página, después de D3. Para probar cambios, edita ese archivo y recarga el HTML; el bloque mostrado aquí es una copia para leer.

HTML inicial dentro de #demo

<svg viewBox="0 0 300 110"><circle cx="70" cy="55" r="20" fill="teal"/><circle cx="210" cy="55" r="20" fill="teal"/></svg>

JavaScript del ejemplo

const circulos = d3.select("#demo").selectAll("circle");
// 1. La lectura devuelve texto: el radio del primer círculo.
const antes = circulos.attr("r");
// 2. La escritura cambia AMBOS círculos.
circulos.attr("r", 30);
// 3. Una selección singular cambia solo el primero.
d3.select("#demo circle").attr("fill", "orange");
d3.select("#salida").text("Radio inicial: " + antes + "\nRadio final: " + circulos.attr("r"));

Resultado



Cómo leerlo
cx, cy, r y fill son atributos SVG. El SVG ya está escrito en el HTML.


attr("r") lee; attr("r", 30) escribe. El número de argumentos cambia la operación.


Si todavía no distingues una selección singular de una múltiple, vuelve a d3.select y d3.selectAll.
Práctica
1. Prueba attr("fill", null) para quitar el atributo.
2. Añade un id al segundo círculo y selecciónalo por ese id.
