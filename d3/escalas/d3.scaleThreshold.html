d3.scaleThreshold

Clasifica con cortes de negocio ordenados. N cortes requieren N+1 salidas.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleThreshold().domain([90,100]).range(["Revisar","Cerca","Cumple"]);
const salida = escala(90);

Crear y utilizar son dos operaciones. d3.scaleThreshold crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: 90 entra en Cerca; 100 entra en Cumple.

Ejemplo paso a paso

JavaScript del ejemplo y resultado para d3.scaleThreshold.

Este ejemplo no necesita una figura inicial. Los resultados se escriben en el panel de salida.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scaleThreshold().domain([90,100]).range(["Revisar","Cerca","Cumple"]);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala(80) + "\n" +
  "Salida 2: " + escala(90) + "\n" +
  "Salida 3: " + escala(100)
);
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. Aquí domain contiene umbrales ordenados, no los extremos de una escala continua. Dos umbrales necesitan tres salidas.
Qué devuelve en este ejemplo. Menos de 90 recibe Revisar; desde 90 hasta antes de 100 recibe Cerca; desde 100 recibe Cumple. El umbral pertenece a la clase que empieza en él.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scalethreshold.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
