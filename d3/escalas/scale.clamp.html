UN ARCHIVO · UN CONCEPTO

scale.clamp

Limita salidas e inversas al dominio y rango. No corrige errores de los datos originales.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleLinear().domain([0, 100]).range([0, 400]);
escala.clamp(true);

Qué representa el nombre de la variable. El título scale indica una escala genérica. En el código, escala es una variable creada previamente; no es una variable que D3 proporcione automáticamente.

Resultado esperado: 600, 400 y 100.

Ejemplo paso a paso

JavaScript del ejemplo y resultado para scale.clamp.

Este ejemplo no necesita una figura inicial. Los resultados se escriben en el panel de salida.

JavaScript del ejemplo

// 1. Preparamos una escala sencilla.
const escala = d3.scaleLinear().domain([0, 100]).range([0, 400]);
const sinLimite = escala(150);
escala.clamp(true);

// 2. Comparamos valores concretos antes y después del método.
d3.select("#salida").text(
  "Sin límite: " + sinLimite + "\n" +
  "Con límite: " + escala(150) + "\n" +
  "Inversa limitada: " + escala.invert(600)
);
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. clamp recibe true o false. Al activarlo se limita la evaluación a los extremos del dominio. No recibe un vector de límites nuevo.
Qué devuelve en este ejemplo. Con [0,100] → [0,400], 150 produce 600 sin clamp y 400 con clamp. La inversa de una posición fuera del rango también queda limitada.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/scaleclamp.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Prueba el dato -20 antes y después de activar clamp: las salidas deben ser -80 y 0.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
