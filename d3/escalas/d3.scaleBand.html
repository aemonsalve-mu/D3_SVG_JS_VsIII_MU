d3.scaleBand

Distribuye categorías en bandas. La salida es el inicio; bandwidth devuelve la anchura. No tiene invert.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleBand().domain(["Norte","Centro","Sur"]).range([0,400]).padding(.2);
const salida = escala("Norte");

Crear y utilizar son dos operaciones. d3.scaleBand crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: Se imprimen tres inicios de banda.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scaleBand().domain(["Norte","Centro","Sur"]).range([0,400]).padding(.2);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala("Norte") + "\n" +
  "Salida 2: " + escala("Centro") + "\n" +
  "Salida 3: " + escala("Sur")
);

// 3. Colocamos las tres marcas usando la escala.
d3.select("#marca-a").attr("x", escala("Norte")).attr("width", escala.bandwidth());
d3.select("#marca-b").attr("x", escala("Centro")).attr("width", escala.bandwidth());
d3.select("#marca-c").attr("x", escala("Sur")).attr("width", escala.bandwidth());
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. domain es el vector de categorías; range contiene solo los extremos del espacio disponible. La escala devuelve el inicio de cada banda, no su centro ni su anchura.
Qué devuelve en este ejemplo. Con rango [0,400] y padding(0.2), las posiciones son 25, 150 y 275; bandwidth() vale 100 y step() vale 125. El ancho útil total de 400 se reparte entre categorías y espacios.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scaleband.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.

        

            
Práctica
1. Cambia padding de 0.2 a 0. El ancho de banda pasa a 400/3; comprueba también las posiciones.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
