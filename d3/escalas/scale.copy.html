scale.copy

Crea otra escala configurable sin modificar la original.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const original = d3.scaleLinear().domain([0, 100]).range([0, 400]);
const copia = original.copy();

Qué representa el nombre de la variable. original y copia son nombres elegidos para guardar dos escalas distintas. No son comandos de D3.

Resultado esperado: a=200; b=100; dominioA sigue [0,100].

Ejemplo paso a paso

JavaScript del ejemplo y resultado para scale.copy.

Este ejemplo no necesita una figura inicial. Los resultados se escriben en el panel de salida.

JavaScript del ejemplo

// 1. Preparamos una escala sencilla.
const original = d3.scaleLinear().domain([0, 100]).range([0, 400]);
const copia = original.copy();
copia.domain([0, 200]);

// 2. Comparamos valores concretos antes y después del método.
d3.select("#salida").text(
  "Original para 50: " + original(50) + "\n" +
  "Copia para 50: " + copia(50) + "\n" +
  "Dominio original: " + original.domain()
);
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. original y copia son variables del ejemplo. copy crea otra escala con la misma configuración inicial para poder cambiarla de forma independiente.
Qué devuelve en este ejemplo. Al modificar el dominio de copia a [0,200], copia(50) vale 100, mientras original(50) sigue valiendo 200 y su dominio sigue siendo [0,100].
