d3.scaleUtc

Transforma fechas en UTC; útil para comparar series entre zonas horarias.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleUtc().domain([new Date("2026-01-01T00:00:00Z"),new Date("2026-01-06T00:00:00Z")]).range([0,500]);
const salida = escala(new Date("2026-01-03T00:00:00Z"));

Crear y utilizar son dos operaciones. d3.scaleUtc crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: Las fechas UTC mantienen una referencia horaria explícita.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scaleUtc().domain([new Date("2026-01-01T00:00:00Z"),new Date("2026-01-06T00:00:00Z")]).range([0,500]);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala(new Date("2026-01-01T00:00:00Z")) + "\n" +
  "Salida 2: " + escala(new Date("2026-01-03T00:00:00Z")) + "\n" +
  "Salida 3: " + escala(new Date("2026-01-06T00:00:00Z"))
);

// 3. Solo cambiamos cx: el círculo ya existe en el HTML.
d3.select("#marca").attr("cx", escala(new Date("2026-01-03T00:00:00Z")));
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. Los extremos especifican fechas y horas UTC. La Z indica esa referencia. El rango contiene posiciones numéricas, no fechas ni duraciones.
Qué devuelve en este ejemplo. La escala devuelve posiciones de 0 a 500. Las marcas de calendario se calculan en UTC y no dependen del cambio de hora local.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scaleutc.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.

1. Cambia el rango a [500,0] y explica por qué el tiempo avanzaría hacia la izquierda.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
