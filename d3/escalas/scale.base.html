UN ARCHIVO · UN CONCEPTO

scale.base

Configura la base de ticks de scaleLog. No cambia posiciones normalizadas con dominio fijo.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleLog().domain([1, 100]).range([0, 400]);
escala.base(2);

Qué representa el nombre de la variable. El título scale indica una escala genérica. En el código, escala es una variable creada previamente; no es una variable que D3 proporcione automáticamente.

Resultado esperado: La posición de 10 se mantiene; cambian los valores de las marcas sugeridas.

Ejemplo paso a paso

JavaScript del ejemplo y resultado para scale.base.

Este ejemplo no necesita una figura inicial. Los resultados se escriben en el panel de salida.

JavaScript del ejemplo

// 1. Preparamos una escala sencilla.
const escala = d3.scaleLog().domain([1, 100]).range([0, 400]);
const antes = escala(10);
const marcasAntes = escala.ticks();
escala.base(2);

// 2. Comparamos valores concretos antes y después del método.
d3.select("#salida").text(
  "Posición antes: " + antes + "\n" +
  "Posición después: " + escala(10) + "\n" +
  "Marcas antes: " + marcasAntes + "\n" +
  "Marcas después: " + escala.ticks()
);
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. base configura la base del logaritmo y la generación de marcas de scaleLog. El argumento es un número positivo distinto de 1.
Qué devuelve en este ejemplo. Con dominio y rango fijos, cambiar de base 10 a 2 mantiene la posición de 10 en 200; cambian las marcas sugeridas. No hace que 10 se coloque en el doble de espacio.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/scalebase.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Compara ticks() antes y después de cambiar la base.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
