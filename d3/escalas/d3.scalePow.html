d3.scalePow

Aplica una potencia preservando el signo. Con exponente 2 enfatiza valores altos.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scalePow().exponent(2).domain([0,100]).range([0,400]);
const salida = escala(50);

Crear y utilizar son dos operaciones. d3.scalePow crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: 50→100: el punto medio de datos ocupa el 25% del rango.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scalePow().exponent(2).domain([0,100]).range([0,400]);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala(0) + "\n" +
  "Salida 2: " + escala(25) + "\n" +
  "Salida 3: " + escala(50) + "\n" +
  "Salida 4: " + escala(100)
);

// 3. Solo cambiamos cx: el círculo ya existe en el HTML.
d3.select("#marca").attr("cx", escala(50));
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. exponent(2) recibe un solo número. domain y range siguen recibiendo sus dos extremos. Para este dominio, la salida es 400 × (dato/100)².
Qué devuelve en este ejemplo. 50 no produce la mitad del rango: devuelve 100, el 25 % de 400. El exponente cambia la transformación, no el número de figuras.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scalepow.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia el exponente de 2 a 1: para 50 debes obtener 200.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
