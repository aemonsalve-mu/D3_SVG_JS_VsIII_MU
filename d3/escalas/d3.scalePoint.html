d3.scalePoint

Distribuye categorías en puntos sin anchura. bandwidth() vale 0; no tiene invert.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scalePoint().domain(["Norte","Centro","Sur"]).range([0,400]);
const salida = escala("Norte");

Crear y utilizar son dos operaciones. d3.scalePoint crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: Norte→0, Centro→200, Sur→400.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scalePoint().domain(["Norte","Centro","Sur"]).range([0,400]);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala("Norte") + "\n" +
  "Salida 2: " + escala("Centro") + "\n" +
  "Salida 3: " + escala("Sur")
);

// 3. Colocamos las tres marcas usando la escala.
d3.select("#marca-a").attr("cx", escala("Norte"));
d3.select("#marca-b").attr("cx", escala("Centro"));
d3.select("#marca-c").attr("cx", escala("Sur"));
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. El vector de categorías se distribuye en posiciones puntuales. La salida indica dónde colocar el centro de una marca. La escala no da un ancho de barra.
Qué devuelve en este ejemplo. Con tres categorías, rango [0,400] y sin padding, las posiciones son 0, 200 y 400. bandwidth() devuelve 0; el radio de los círculos se configura aparte.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scalepoint.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia el extremo del rango de 400 a 600: las posiciones deben ser 0, 300 y 600.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
