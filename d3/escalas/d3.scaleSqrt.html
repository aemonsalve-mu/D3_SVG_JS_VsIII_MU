d3.scaleSqrt

Raíz cuadrada con signo. Para valores no negativos, si dominio y rango empiezan en 0, el área de las burbujas es proporcional al valor al usar la salida como radio.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleSqrt().domain([0,100]).range([0,30]);
const salida = escala(25);

Crear y utilizar son dos operaciones. d3.scaleSqrt crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: 25→15 y 100→30; las áreas guardan proporción 1:4.

JavaScript del ejemplo y resultado para d3.scaleSqrt.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scaleSqrt().domain([0,100]).range([0,30]);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala(25) + "\n" +
  "Salida 2: " + escala(100)
);

// 3. La escala calcula radios; las áreas guardan proporción.
d3.select("#pequena").attr("r", escala(25));
d3.select("#grande").attr("r", escala(100));
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. El dato representa una cantidad; la salida se usa como radio. [0,30] no son dos radios de dos figuras: son los extremos de salida de una misma escala.
Qué devuelve en este ejemplo. Los datos 25 y 100 producen radios 15 y 30. El diámetro se duplica y el área se multiplica por cuatro. Para áreas proporcionales se necesitan datos no negativos, dominio desde 0 y rango desde 0.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scalesqrt.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Sustituye scaleSqrt por scaleLinear con el mismo dominio y rango. Compara radios y áreas para 25 y 100.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
