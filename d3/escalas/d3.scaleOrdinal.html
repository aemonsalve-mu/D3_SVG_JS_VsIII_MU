d3.scaleOrdinal

Asigna salidas discretas a categorías. Explicita el dominio para estabilizar los colores.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleOrdinal().domain(["Norte","Centro","Sur"]).range(["teal","orange","purple"]);
const salida = escala("Norte");

Crear y utilizar son dos operaciones. d3.scaleOrdinal crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: Cada zona recibe su color.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scaleOrdinal().domain(["Norte","Centro","Sur"]).range(["teal","orange","purple"]);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala("Norte") + "\n" +
  "Salida 2: " + escala("Centro") + "\n" +
  "Salida 3: " + escala("Sur")
);

// 3. Aplicamos cada color a un rectángulo ya escrito en el HTML.
d3.select("#color-a").attr("fill", escala("Norte"));
d3.select("#color-b").attr("fill", escala("Centro"));
d3.select("#color-c").attr("fill", escala("Sur"));
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. domain recibe categorías y range una lista de colores. Aquí cada posición del dominio corresponde a la misma posición del rango. No se interpola una distancia numérica.
Qué devuelve en este ejemplo. Norte recibe teal, Centro orange y Sur purple. Si faltan colores, D3 vuelve a utilizarlos. Conviene fijar el dominio para que el orden de llegada no cambie las asignaciones.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scaleordinal.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Intercambia los dos primeros colores del rango y predice qué figuras cambian.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
