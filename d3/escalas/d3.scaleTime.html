d3.scaleTime

Transforma fechas en la zona horaria local. Los intervalos de calendario no tienen duración idéntica.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleTime().domain([new Date(2026,0,1),new Date(2026,0,6)]).range([0,500]);
const salida = escala(new Date(2026,0,3));

Crear y utilizar son dos operaciones. d3.scaleTime crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: El 1 de enero se sitúa en 0 y el 6 en 500.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scaleTime().domain([new Date(2026,0,1),new Date(2026,0,6)]).range([0,500]);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala(new Date(2026, 0, 1)) + "\n" +
  "Salida 2: " + escala(new Date(2026, 0, 3)) + "\n" +
  "Salida 3: " + escala(new Date(2026, 0, 6))
);

// 3. Solo cambiamos cx: el círculo ya existe en el HTML.
d3.select("#marca").attr("cx", escala(new Date(2026, 0, 3)));
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. Los extremos son objetos Date. En new Date(2026,0,1), los meses empiezan en 0: 0 es enero. El rango [0,500] contiene posiciones del dibujo.
Qué devuelve en este ejemplo. Las fechas del 1 al 6 de enero se sitúan entre 0 y 500. La escala trabaja con fechas y calendario local; al mostrar un Date como ISO puede aparecer otra hora por la zona horaria.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scaletime.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia solo el extremo del rango a 1000. Las posiciones se duplican; las fechas de entrada siguen siendo las mismas.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
