d3.scaleQuantize

Divide un intervalo en clases de igual anchura; no equilibra el número de observaciones.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleQuantize().domain([0,100]).range(["Bajo","Medio","Alto"]);
const salida = escala(50);

Crear y utilizar son dos operaciones. d3.scaleQuantize crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: Cortes en 33,33 y 66,67.

Ejemplo paso a paso

JavaScript del ejemplo y resultado para d3.scaleQuantize.

Este ejemplo no necesita una figura inicial. Los resultados se escriben en el panel de salida.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scaleQuantize().domain([0,100]).range(["Bajo","Medio","Alto"]);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala(0) + "\n" +
  "Salida 2: " + escala(50) + "\n" +
  "Salida 3: " + escala(100)
);
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. El dominio tiene dos extremos numéricos; el rango tiene tres clases. D3 divide la amplitud de 100 en tres intervalos de igual anchura.
Qué devuelve en este ejemplo. Los cortes son 100/3 y 200/3. Las salidas son etiquetas, no coordenadas ni dimensiones SVG. Para colorear, podrías utilizar tres colores como rango.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scalequantize.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia el máximo a 120: los cortes deben ser 40 y 80.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
