UN ARCHIVO · UN CONCEPTO

d3.scaleDiverging

Usa tres valores de dominio: mínimo, centro significativo y máximo. Carece de invert.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleDiverging(d3.interpolateRdBu).domain([-20,0,20]);
const salida = escala(0);

Crear y utilizar son dos operaciones. d3.scaleDiverging crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: Cero recibe el color central.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scaleDiverging(d3.interpolateRdBu).domain([-20,0,20]);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala(-20) + "\n" +
  "Salida 2: " + escala(0) + "\n" +
  "Salida 3: " + escala(20)
);

// 3. Aplicamos cada color a un rectángulo ya escrito en el HTML.
d3.select("#color-a").attr("fill", escala(-20));
d3.select("#color-b").attr("fill", escala(0));
d3.select("#color-c").attr("fill", escala(20));
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. Este dominio contiene tres valores: extremo inferior, centro significativo y extremo superior. No son las dimensiones x, y y z de una figura.
Qué devuelve en este ejemplo. El valor 0 recibe el color central. El punto central no tiene por qué ser la media aritmética de los extremos. La salida sigue siendo un color.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scalediverging.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia el centro de 0 a 5 y compara los colores de los mismos valores.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
