d3.scaleQuantile

Calcula cortes a partir de toda la muestra. Los empates pueden impedir clases de igual tamaño.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleQuantile().domain([5,8,9,10,12,15,20,90,100]).range(["Bajo","Medio","Alto"]);
const salida = escala(12);

Crear y utilizar son dos operaciones. d3.scaleQuantile crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: Los cortes son aproximadamente 9,67 y 16,67. Las entradas 8, 12 y 90 se clasifican como Bajo, Medio y Alto.

Ejemplo paso a paso

JavaScript del ejemplo y resultado para d3.scaleQuantile.

Este ejemplo no necesita una figura inicial. Los resultados se escriben en el panel de salida.

JavaScript del ejemplo

// Los cortes se calculan a partir de toda la muestra.
const escala = d3.scaleQuantile().domain([5,8,9,10,12,15,20,90,100]).range(["Bajo","Medio","Alto"]);
d3.select("#salida").text(
  "Salida 1: " + escala(8) + "\n" +
  "Salida 2: " + escala(12) + "\n" +
  "Salida 3: " + escala(90) + "\n" +
  "Cortes calculados: " + escala.quantiles()
);
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. En esta familia domain sí recibe la muestra completa de observaciones. D3 calcula cuantiles a partir de esos datos y del número de clases del rango.
Qué devuelve en este ejemplo. Con tres clases, los cortes son aproximadamente 9.67 y 16.67. Las amplitudes no son iguales; los empates pueden impedir clases con igual número de observaciones.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scalequantile.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Añade tres valores 100 a la muestra y observa cómo cambian los cortes, manteniendo las mismas tres clases.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
