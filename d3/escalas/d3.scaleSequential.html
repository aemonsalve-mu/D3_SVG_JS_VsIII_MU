d3.scaleSequential

Asigna una progresión de color a cantidades ordenadas. Usa interpolator, no interpolate; carece de invert.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleSequential(d3.interpolateViridis).domain([0,100]);
const salida = escala(50);

Crear y utilizar son dos operaciones. d3.scaleSequential crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: Se obtiene un color por cada valor.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scaleSequential(d3.interpolateViridis).domain([0,100]);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala(0) + "\n" +
  "Salida 2: " + escala(50) + "\n" +
  "Salida 3: " + escala(100)
);

// 3. Aplicamos cada color a un rectángulo ya escrito en el HTML.
d3.select("#color-a").attr("fill", escala(0));
d3.select("#color-b").attr("fill", escala(50));
d3.select("#color-c").attr("fill", escala(100));
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. El dominio tiene dos extremos y un interpolador genera la salida. En este ejemplo las salidas son colores; no representan anchuras o coordenadas.
Qué devuelve en este ejemplo. El dato se normaliza respecto al dominio. Cambiar la gama de color no cambia el tamaño del rectángulo; el tamaño está definido en el HTML.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scalesequential.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Sustituye interpolateViridis por interpolateBlues y comprueba que cambia el color, no la geometría.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
