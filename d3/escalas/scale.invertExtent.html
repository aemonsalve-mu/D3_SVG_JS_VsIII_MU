UN ARCHIVO · UN CONCEPTO

scale.invertExtent

Devuelve los límites de una clase en quantize, quantile y threshold. En threshold, la clase incluye el límite inferior y excluye el superior; undefined indica un extremo sin límite.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleThreshold().domain([50, 80]).range(["Bajo", "Medio", "Alto"]);
const limites = escala.invertExtent("Medio");

Qué representa el nombre de la variable. El título scale indica una escala genérica. En el código, escala es una variable creada previamente; no es una variable que D3 proporcione automáticamente.

Resultado esperado: Medio: límites [50,80], correspondientes a 50 ≤ x < 80; Bajo: x < 50, con límite inferior undefined.

Ejemplo paso a paso

JavaScript del ejemplo y resultado para scale.invertExtent.

Este ejemplo no necesita una figura inicial. Los resultados se escriben en el panel de salida.

JavaScript del ejemplo

// 1. Preparamos una escala sencilla.
const escala = d3.scaleThreshold().domain([50, 80]).range(["Bajo", "Medio", "Alto"]);
const medio = escala.invertExtent("Medio");
const bajo = escala.invertExtent("Bajo");

// 2. Comparamos valores concretos antes y después del método.
d3.select("#salida").text(
  "Límite inferior de Medio: " + medio[0] + "\n" +
  "Límite superior de Medio: " + medio[1] + "\n" +
  "Límite inferior de Bajo: " + bajo[0] + "\n" +
  "Límite superior de Bajo: " + bajo[1]
);
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. invertExtent recibe una clase de salida y devuelve un array de dos límites del dominio. limites[0] es el inferior y limites[1] el superior. No devuelve [ancho,alto].
Qué devuelve en este ejemplo. Con umbrales [50,80], Medio corresponde a 50 ≤ x < 80. Para Bajo, el límite inferior es undefined: no hay límite inferior. En quantile y quantize también devuelve límites de clase, con sus propias reglas.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
