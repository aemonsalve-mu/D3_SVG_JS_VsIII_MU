scale.interpolate

Define la fábrica de interpolación de una escala continua compatible. Para secuenciales usa interpolator.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleLinear().domain([0, 100]).range(["white", "teal"]);
escala.interpolate(d3.interpolateHcl);

Qué representa el nombre de la variable. El título scale indica una escala genérica. En el código, escala es una variable creada previamente; no es una variable que D3 proporcione automáticamente.

Resultado esperado: Se muestra el color calculado para 50.

JavaScript del ejemplo

// 1. Preparamos una escala sencilla.
const escala = d3.scaleLinear().domain([0, 100]).range(["white", "teal"]);
escala.interpolate(d3.interpolateHcl);

// 2. Comparamos valores concretos antes y después del método.
d3.select("#salida").text(
  "Color para 50: " + escala(50)
);
d3.select("#muestra").attr("fill", escala(50));
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. interpolate elige la fábrica que calcula los valores intermedios entre dos salidas de una escala continua. En esta ficha son colores.
Qué devuelve en este ejemplo. La escala sigue teniendo dominio [0,100] y rango [white,teal]. Solo cambia cómo se construyen los colores intermedios. Para escalas secuenciales se utiliza interpolator, no este método.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/scaleinterpolate.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia interpolateHcl por interpolateRgb y compara el color para el mismo dato 50.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
