UN ARCHIVO · UN CONCEPTO

scale.domain

Configura las entradas de la escala; sin argumentos devuelve su dominio. Las fechas y categorías también pueden ser dominios.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

d3.max(datos) devuelve el máximo de este vector de números. Se define aquí antes de usarlo para construir los dos extremos del dominio.

const datos = [20, 50, 100];
const maximo = d3.max(datos);
const escala = d3.scaleLinear().range([0,400]);
escala.domain([0,maximo]);

Define primero cada nombre. datos contiene tres observaciones. maximo guarda un único número, 100. escala guarda la función que transforma esas observaciones. Ninguno de estos nombres es un comando reservado de D3.

Resultado esperado: Máximo inicial 100 y nuevo 200; el dato 50 pasa de salida 200 a salida 100.

Ejemplo paso a paso

JavaScript del ejemplo y resultado para scale.domain.

Este ejemplo no necesita una figura inicial. Los resultados se escriben en el panel de salida.

JavaScript del ejemplo

// 1. datos es el vector de observaciones numéricas.
const datos = [20, 50, 100];
// d3.max devuelve el mayor valor del vector: aquí 100.
const maximo = d3.max(datos);
const escala = d3.scaleLinear().domain([0, maximo]).range([0, 400]);
const antes = escala(50);

// 2. Cambiamos el tercer dato. La escala no se actualiza sola.
datos[2] = 200;
escala.domain([0, d3.max(datos)]);
const despues = escala(50);

d3.select("#salida").text(
  "Máximo inicial: " + maximo + "\n" +
  "Dato 50 antes: " + antes + "\n" +
  "Máximo nuevo: " + d3.max(datos) + "\n" +
  "Dato 50 después: " + despues
);
Cómo leerlo, paso a paso
Una instrucción auxiliar definida aquí. d3.max(datos) devuelve el mayor valor del array; no necesita que esté ordenado. Estos datos son números, no cadenas de texto procedentes de un CSV sin convertir. Esta función no dibuja nada.
Una muestra y dos extremos tienen papeles distintos. datos es [20,50,100], pero el dominio de esta escala de barras es [0,100]. No pases toda la muestra a domain suponiendo que cada número creará una barra: en una escala lineal, un dominio con más de dos valores define tramos y necesita el rango correspondiente.
El dominio debe actualizarse de manera explícita. datos[2]=200 cambia el tercer dato. No reemplaza el array completo. const fija la referencia de la variable, pero no congela sus elementos. Después se vuelve a llamar domain con el nuevo máximo. La escala no observa automáticamente los cambios del vector.
Qué ocurre con la longitud. El rango sigue siendo [0,400]. Con máximo 100, el dato 50 produce 200; con máximo 200, produce 100. Cambia la proporción entre datos y longitudes, no el ancho del lienzo. Revisa las barras horizontales y vectores y dimensiones.
Edita js/scaledomain.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia el nuevo tercer dato a 400: la salida del dato 50 debe ser 50.
2. Reordena los valores del vector inicial. d3.max debe seguir encontrando su máximo, sin depender de la última posición.
3. Comenta la segunda llamada a domain: comprueba que cambiar el array no modifica por sí solo la escala.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
