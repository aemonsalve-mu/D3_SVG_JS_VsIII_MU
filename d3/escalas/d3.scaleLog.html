d3.scaleLog

Representa factores multiplicativos. El dominio no puede incluir ni cruzar cero.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleLog().domain([1,1000]).range([0,300]);
const salida = escala(10);

Crear y utilizar son dos operaciones. d3.scaleLog crea una función que guardamos en escala. Después, escala(valor) transforma una entrada. El nombre escala es una variable del ejemplo.

Resultado esperado: Cada multiplicación por 10 añade 100 unidades.

JavaScript del ejemplo

// 1. domain contiene los datos; range, las salidas.
const escala = d3.scaleLog().domain([1,1000]).range([0,300]);

// 2. Llamamos a la escala con valores concretos.
d3.select("#salida").text(
  "Salida 1: " + escala(1) + "\n" +
  "Salida 2: " + escala(10) + "\n" +
  "Salida 3: " + escala(100) + "\n" +
  "Salida 4: " + escala(1000)
);

// 3. Solo cambiamos cx: el círculo ya existe en el HTML.
d3.select("#marca").attr("cx", escala(100));
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. El dominio [1,1000] contiene dos extremos positivos; no es el vector completo de observaciones. Cada multiplicación de la entrada por 10 añade 100 unidades de salida.
Qué devuelve en este ejemplo. Las entradas 1, 10, 100 y 1000 se sitúan aproximadamente en 0, 100, 200 y 300. La separación es uniforme por razones multiplicativas, no por diferencias.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/d3scalelog.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Compara dónde se coloca 10 con una escala lineal del mismo dominio. No incluyas cero ni mezcles signos en un dominio logarítmico.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
