scale.constant

Controla la región suave alrededor de cero en symlog.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleSymlog().domain([-100, 100]).range([0, 400]).constant(10);
escala.constant(1);

Qué representa el nombre de la variable. El título scale indica una escala genérica. En el código, escala es una variable creada previamente; no es una variable que D3 proporcione automáticamente.

Resultado esperado: Cambia la posición de 10; cero conserva el centro.

Ejemplo paso a paso

JavaScript del ejemplo y resultado para scale.constant.

Este ejemplo no necesita una figura inicial. Los resultados se escriben en el panel de salida.

JavaScript del ejemplo

// 1. Preparamos una escala sencilla.
const escala = d3.scaleSymlog().domain([-100, 100]).range([0, 400]).constant(10);
const antes = escala(10);
escala.constant(1);

// 2. Comparamos valores concretos antes y después del método.
d3.select("#salida").text(
  "Con constante 10: " + antes + "\n" +
  "Con constante 1: " + escala(10)
);
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. constant regula la transición de symlog alrededor de cero. Es un parámetro de la transformación, no una longitud SVG ni un desplazamiento del eje.
Qué devuelve en este ejemplo. Para el dato 10, cambiar la constante de 10 a 1 cambia la salida aproximada de 257.81 a 303.91. El cero permanece en el centro si el dominio y rango son simétricos.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/scaleconstant.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Consulta escala(0) con ambas constantes: debe seguir siendo 200.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
