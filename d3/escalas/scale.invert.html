UN ARCHIVO · UN CONCEPTO

scale.invert

Recupera un dato desde una salida numérica. No existe en todas las familias ni invierte un rango de colores.

Empieza por scaleLinear, domain, range e invert. Después compara categorías con scaleBand y scaleOrdinal. Las escalas logarítmicas, cuantiles e interpolación son pasos posteriores.

Sintaxis

const escala = d3.scaleLinear().domain([0, 100]).range([40, 500]);
escala.invert(270);

Qué representa el nombre de la variable. El título scale indica una escala genérica. En el código, escala es una variable creada previamente; no es una variable que D3 proporcione automáticamente.

Resultado esperado: 50.

Ejemplo paso a paso

JavaScript del ejemplo y resultado para scale.invert.

Este ejemplo no necesita una figura inicial. Los resultados se escriben en el panel de salida.

JavaScript del ejemplo

// 1. Preparamos una escala sencilla.
const escala = d3.scaleLinear().domain([0, 100]).range([40, 500]);

// 2. Comparamos valores concretos antes y después del método.
d3.select("#salida").text(
  "Dato para la posición 270: " + escala.invert(270)
);
Cómo leerlo, paso a paso
Cómo se interpreta el argumento. invert realiza el recorrido inverso: recibe una posición numérica del rango y devuelve el dato asociado. No devuelve el índice de una figura.
Qué devuelve en este ejemplo. Con dominio [0,100] y rango [40,500], la posición 270 corresponde al dato 50. No todas las familias tienen invert, y no sirve para invertir un rango de colores.
Vectores y medidas. Un array puede representar datos, categorías, límites, clases o dimensiones. Identifica su significado antes de usar sus posiciones. Consulta vectores y dimensiones y distingue longitud de posición vertical.
Edita js/scaleinvert.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Comprueba escala.invert(40) y escala.invert(500): deben devolver 0 y 100.
2. Modifica una entrada concreta y compara su salida antes de cambiar la figura.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
