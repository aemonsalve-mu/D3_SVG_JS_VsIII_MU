UN ARCHIVO · UN CONCEPTO

transition.ease

Función de ritmo de la animación.

Estudia antes selección, atributos y SVG. Empieza por line y una transición sencilla; las áreas, arcos y sectores añaden conceptos.

Sintaxis

const circulo = d3.select("#circulo");
circulo.transition().ease(d3.easeLinear).attr("cx",450);

Qué representan los números. ease recibe una función que transforma el progreso temporal normalizado, de 0 a 1. No recibe un vector de coordenadas.

Resultado esperado: Animar aplica el parámetro al movimiento.

Ejemplo D3 y SVG

JavaScript del ejemplo y resultado para transition.ease.

HTML inicial dentro de #demo

<svg viewBox="0 0 560 150"><circle id="circulo" cx="50" cy="70" r="22" fill="teal"/></svg>
<button id="animar">Animar</button>

JavaScript del ejemplo

const circulo = d3.select("#circulo");

// La animación empieza al pulsar el botón del HTML.
d3.select("#animar").on("click", function() {
  circulo.interrupt().attr("cx", 50);
  circulo.transition().ease(d3.easeLinear).attr("cx", 450);
});
Cómo leerlo, paso a paso
Qué cambia y qué permanece. d3.easeLinear produce progreso uniforme en este cambio numérico de cx. No es la misma función que d3.scaleLinear, que transforma valores entre dominio y rango.
Para distinguir datos, posiciones y dimensiones, revisa vectores y dimensiones y viewBox. El HTML contiene la figura inicial; el .js calcula sus atributos o prepara la interacción.
Práctica
Compara d3.easeLinear con d3.easeCubicInOut manteniendo iguales distancia y duración.
Cambia una sola medida y predice el resultado antes de recargar el HTML.
