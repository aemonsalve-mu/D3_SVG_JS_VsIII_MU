UN ARCHIVO · UN CONCEPTO

d3.symbol

Genera paths para símbolos. size representa área, no radio.

Estudia antes selección, atributos y SVG. Empieza por line y una transición sencilla; las áreas, arcos y sectores añaden conceptos.

Sintaxis

const simbolo = d3.symbol().type(d3.symbolTriangle).size(1200);

Qué representan los números. size(1200) representa el área nominal del símbolo en unidades SVG cuadradas. No es ancho, alto ni radio.

Resultado esperado: Triángulo centrado.

Ejemplo D3 y SVG

JavaScript del ejemplo y resultado para d3.symbol.

HTML inicial dentro de #demo

<svg viewBox="0 0 300 160"><path id="forma" transform="translate(150,80)" fill="teal"/></svg>

JavaScript del ejemplo

// size es el área del símbolo, no su radio.
const simbolo = d3.symbol().type(d3.symbolTriangle).size(1200);
d3.select("#forma").attr("d", simbolo());
Cómo leerlo, paso a paso
Qué cambia y qué permanece. type elige la geometría y translate(150,80) la sitúa. Mantener la misma área no implica que dos tipos de símbolo tengan la misma caja de anchura y altura.
Para distinguir datos, posiciones y dimensiones, revisa vectores y dimensiones y viewBox. El HTML contiene la figura inicial; el .js calcula sus atributos o prepara la interacción.
Práctica
Multiplica size por cuatro: las dimensiones lineales de este triángulo deben duplicarse.
Cambia una sola medida y predice el resultado antes de recargar el HTML.
