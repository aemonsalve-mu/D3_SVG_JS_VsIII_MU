selection.interrupt

Interrumpe la transición activa y cancela las pendientes del nombre indicado en los nodos seleccionados. Sin nombre, actúa sobre las transiciones sin nombre; no afecta a los descendientes.

Estudia antes selección, atributos y SVG. Empieza por line y una transición sencilla; las áreas, arcos y sectores añaden conceptos.

Sintaxis

const circulo = d3.select("#circulo");
circulo.interrupt();

Qué representan los números. interrupt detiene la transición en su estado actual. No elimina el círculo ni lo devuelve al inicio.

Resultado esperado: Parar detiene el círculo donde se encuentra.

Ejemplo D3 y SVG

JavaScript del ejemplo y resultado para selection.interrupt.

HTML inicial dentro de #demo

<svg viewBox="0 0 560 150"><circle id="circulo" cx="50" cy="70" r="22" fill="teal"/></svg>
<button id="animar">Iniciar</button>
<button id="parar">Parar</button>

JavaScript del ejemplo

const circulo = d3.select("#circulo");

// La animación empieza al pulsar el botón del HTML.
d3.select("#animar").on("click", function() {
  circulo.interrupt().attr("cx", 50);
  circulo.transition().duration(4000).attr("cx", 450);
});

d3.select("#parar").on("click", function() {
  circulo.interrupt();
});
Cómo leerlo, paso a paso
Qué cambia y qué permanece. Iniciar reinicia cx=50 y programa un movimiento hasta 450 durante 4000 ms. Parar conserva el cx que tenga en ese instante. La posición resultante es un número del SVG.
Para distinguir datos, posiciones y dimensiones, revisa vectores y dimensiones y viewBox. El HTML contiene la figura inicial; el .js calcula sus atributos o prepara la interacción.
Práctica
Pulsa Parar a mitad del recorrido. Después vuelve a Iniciar para distinguir detener y reiniciar.
Cambia una sola medida y predice el resultado antes de recargar el HTML.
