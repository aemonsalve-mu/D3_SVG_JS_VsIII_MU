UN ARCHIVO · UN CONCEPTO

d3.line

Genera el atributo d de un path desde una serie; no crea nodos.

Estudia antes selección, atributos y SVG. Empieza por line y una transición sencilla; las áreas, arcos y sectores añaden conceptos.

Sintaxis

const puntos = [[30,130],[150,90],[270,110],[400,25]];
const linea = d3.line();
const ruta = linea(puntos);

Qué representan los números. Cada fila de puntos es una pareja [x,y]. [30,130] significa una posición: x=30,y=130; no una figura de ancho 30 y alto 130.

Resultado esperado: Una línea une los cuatro puntos.

Ejemplo D3 y SVG

JavaScript del ejemplo y resultado para d3.line.

HTML inicial dentro de #demo

<svg viewBox="0 0 500 170"><path id="forma" fill="none" stroke="teal"/></svg>

JavaScript del ejemplo

// Cada pareja contiene [x, y]. d3.line ya usa esas posiciones por defecto.
const puntos = [[30, 130], [150, 90], [270, 110], [400, 25]];
const linea = d3.line();
const ruta = linea(puntos);
d3.select("#forma").attr("d", ruta);
d3.select("#salida").text(ruta);
Cómo leerlo, paso a paso
Qué cambia y qué permanece. d3.line usa por defecto d[0] como x y d[1] como y. Estos valores ya son coordenadas SVG. Si fueran tiempo y ventas en sus unidades originales, habría que transformarlos antes mediante escalas.
Para distinguir datos, posiciones y dimensiones, revisa vectores y dimensiones y viewBox. El HTML contiene la figura inicial; el .js calcula sus atributos o prepara la interacción.
Práctica
Cambia el segundo punto de [150,90] a [150,40]: solo debe subir ese vértice. El lienzo y los demás puntos no cambian.
Cambia una sola medida y predice el resultado antes de recargar el HTML.
