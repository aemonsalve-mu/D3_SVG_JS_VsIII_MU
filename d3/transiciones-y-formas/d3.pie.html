UN ARCHIVO · UN CONCEPTO

d3.pie

Calcula ángulos proporcionales a valores positivos; no dibuja. Su salida suele combinarse con d3.arc para generar sectores.

Estudia antes selección, atributos y SVG. Empieza por line y una transición sencilla; las áreas, arcos y sectores añaden conceptos.

Sintaxis

const calcular = d3.pie().sort(null);
const sectores = calcular([40,70,100]);

Qué representan los números. El vector [40,70,100] contiene cantidades, no tamaños ni coordenadas. pie calcula para cada dato los ángulos de un sector.

Resultado esperado: Tres sectores cuya suma angular es 2π.

Ejemplo D3 y SVG

JavaScript del ejemplo y resultado para d3.pie.

Este ejemplo no necesita una figura inicial. Los resultados se escriben en el panel de salida.

JavaScript del ejemplo

// pie calcula ángulos; no dibuja por sí sola.
const calcular = d3.pie().sort(null);
const sectores = calcular([40, 70, 100]);
// [0] es el primer sector; value, startAngle y endAngle son sus propiedades.
d3.select("#salida").text(
  "Valor del primer sector: " + sectores[0].value + "\n" +
  "Ángulo inicial: " + sectores[0].startAngle + "\n" +
  "Ángulo final: " + sectores[0].endAngle + "\n" +
  "Fin del último sector: " + sectores[2].endAngle
);
Cómo leerlo, paso a paso
Qué cambia y qué permanece. La suma es 210. El primer ángulo mide (40/210)×2π, aproximadamente 1.197 radianes. La suma angular completa es 2π. pie no crea el path ni decide el radio; para dibujar se utiliza arc.
Para distinguir datos, posiciones y dimensiones, revisa vectores y dimensiones y viewBox. El HTML contiene la figura inicial; el .js calcula sus atributos o prepara la interacción.
Práctica
Duplica todas las cantidades a [80,140,200]: los ángulos deben permanecer iguales porque las proporciones no cambian.
Cambia una sola medida y predice el resultado antes de recargar el HTML.
