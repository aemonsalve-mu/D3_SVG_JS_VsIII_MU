UN ARCHIVO · UN CONCEPTO

d3.area

Genera un path cerrado entre dos límites.

Estudia antes selección, atributos y SVG. Empieza por line y una transición sencilla; las áreas, arcos y sectores añaden conceptos.

Sintaxis

const puntos = [[30,130],[150,90],[270,110],[400,25]];
const area = d3.area().x(function(d) { return d[0]; }).y0(150).y1(function(d) { return d[1]; });

Qué representan los números. puntos contiene parejas [x,y] de la frontera superior; y0(150) fija la base común. Los dos límites son posiciones, no alturas.

Resultado esperado: Área rellena hasta la línea base 150.

JavaScript del ejemplo

const puntos = [[30, 130], [150, 90], [270, 110], [400, 25]];
// d es una pareja [x, y]; d[0] es x y d[1] es y.
const area = d3.area().x(function(d) {
  return d[0];
}).y0(150).y1(function(d) {
  return d[1];
});
d3.select("#forma").attr("d", area(puntos));
Cómo leerlo, paso a paso
Qué cambia y qué permanece. En el punto [150,90], la distancia vertical hasta la base es 150−90=60. La función de x devuelve d[0] y la de y1 devuelve d[1]. return entrega una coordenada por punto.
Para distinguir datos, posiciones y dimensiones, revisa vectores y dimensiones y viewBox. El HTML contiene la figura inicial; el .js calcula sus atributos o prepara la interacción.
Práctica
Cambia y0 de 150 a 160: la base baja 10 y el área se amplía sin mover los puntos de la frontera superior.
Cambia una sola medida y predice el resultado antes de recargar el HTML.
