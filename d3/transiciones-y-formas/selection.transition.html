selection.transition

Inicia una transición de atributos o estilos. No sustituye el enlace de datos.

Estudia antes selección, atributos y SVG. Empieza por line y una transición sencilla; las áreas, arcos y sectores añaden conceptos.

Sintaxis

const circulo = d3.select("#circulo");
circulo.transition().duration(700).attr("cx",450);

Qué representan los números. El círculo conserva r=22 y cy=70. La transición cambia únicamente cx, desde 50 hasta 450: un desplazamiento horizontal de 400 unidades.

Resultado esperado: El círculo se mueve al pulsar Mover.

Ejemplo D3 y SVG

JavaScript del ejemplo y resultado para selection.transition.

HTML inicial dentro de #demo

<svg viewBox="0 0 560 150"><circle id="circulo" cx="50" cy="70" r="22" fill="teal"/></svg>
<button id="animar">Mover</button>

JavaScript del ejemplo

const circulo = d3.select("#circulo");

// La animación empieza al pulsar el botón del HTML.
d3.select("#animar").on("click", function() {
  circulo.interrupt().attr("cx", 50);
  circulo.transition().duration(700).attr("cx", 450);
});
Cómo leerlo, paso a paso
Qué cambia y qué permanece. duration(700) controla tiempo en milisegundos, no distancia ni dimensiones. Un nuevo clic detiene la animación previa y coloca el círculo en el punto inicial para repetir el ejemplo.
Para distinguir datos, posiciones y dimensiones, revisa vectores y dimensiones y viewBox. El HTML contiene la figura inicial; el .js calcula sus atributos o prepara la interacción.
Práctica
Cambia el destino a cx=350: el recorrido pasa a 300, pero sigue durando 700 ms.
Cambia una sola medida y predice el resultado antes de recargar el HTML.
