d3.arc

Genera sectores y anillos a partir de radios y ángulos en radianes.

Estudia antes selección, atributos y SVG. Empieza por line y una transición sencilla; las áreas, arcos y sectores añaden conceptos.

Sintaxis

const arco = d3.arc().innerRadius(40).outerRadius(85);
arco.startAngle(0).endAngle(Math.PI * 1.5);

Qué representan los números. innerRadius=40 y outerRadius=85 son radios, no diámetros. startAngle y endAngle se expresan en radianes, no en grados.

Resultado esperado: Tres cuartos de un anillo.

Ejemplo D3 y SVG

JavaScript del ejemplo y resultado para d3.arc.

HTML inicial dentro de #demo

<svg viewBox="0 0 300 220"><path id="forma" transform="translate(150,110)" fill="teal"/></svg>

JavaScript del ejemplo

// Radios en unidades SVG; ángulos en radianes.
const arco = d3.arc().innerRadius(40).outerRadius(85);
arco.startAngle(0).endAngle(Math.PI * 1.5);
d3.select("#forma").attr("d", arco());
Cómo leerlo, paso a paso
Qué cambia y qué permanece. El ángulo final 1.5π corresponde a 270°. La traslación del path a (150,110) sitúa el centro, sin cambiar los radios. El grosor del anillo es 85−40=45.
Para distinguir datos, posiciones y dimensiones, revisa vectores y dimensiones y viewBox. El HTML contiene la figura inicial; el .js calcula sus atributos o prepara la interacción.
Práctica
Cambia innerRadius a 0 para obtener un sector sin hueco; conserva outerRadius para mantener el diámetro exterior 170.
Cambia una sola medida y predice el resultado antes de recargar el HTML.
