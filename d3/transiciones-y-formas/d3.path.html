d3.path

Construye un path con instrucciones similares a Canvas y lo serializa.

Estudia antes selección, atributos y SVG. Empieza por line y una transición sencilla; las áreas, arcos y sectores añaden conceptos.

Sintaxis

const camino = d3.path();
camino.moveTo(30,120);
camino.lineTo(150,30);
camino.lineTo(270,120);
camino.closePath();

Qué representan los números. moveTo y lineTo reciben parejas x,y. Cada pareja representa un punto. closePath añade el segmento que vuelve al inicio.

Resultado esperado: Triángulo y su cadena de instrucciones.

JavaScript del ejemplo

const camino = d3.path();
camino.moveTo(30, 120);
camino.lineTo(150, 30);
camino.lineTo(270, 120);
camino.closePath();
// El trazado se convierte a texto para el atributo d.
d3.select("#forma").attr("d", camino.toString());
d3.select("#salida").text(camino.toString());
Cómo leerlo, paso a paso
Qué cambia y qué permanece. El trazado empieza en (30,120), pasa por (150,30) y (270,120). toString lo convierte en instrucciones del atributo d de un path existente. No crea el nodo SVG.
Para distinguir datos, posiciones y dimensiones, revisa vectores y dimensiones y viewBox. El HTML contiene la figura inicial; el .js calcula sus atributos o prepara la interacción.
Práctica
Mueve el punto superior de (150,30) a (150,60): el triángulo debe ser menos alto, manteniendo la base.
Cambia una sola medida y predice el resultado antes de recargar el HTML.
