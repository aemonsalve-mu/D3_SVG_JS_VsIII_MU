svg.ellipse

Elipse con radios horizontal y vertical independientes.

Empieza por svg, rect, circle, line y text. defs, gradientes, recortes, máscaras y símbolos son ampliaciones.

Sintaxis

Antes de usar JavaScript con SVG

document.querySelector busca un nodo por su selector. setAttribute escribe un atributo y textContent muestra texto. Estudia primero la selección del DOM nativo y setAttribute. Los corchetes leen posiciones del array, empezando por 0.

const radios = [100, 40];
const elipse = document.querySelector("#elipse");
elipse.setAttribute("rx", radios[0]);
elipse.setAttribute("ry", radios[1]);

Qué significa cada medida. Una elipse tiene dos radios: rx horizontal y ry vertical. La pareja radios=[100,40] produce anchura 200 y altura 80, porque son diámetros.

Resultado esperado: La elipse tiene radios 100 y 40, por tanto mide 200 × 80.

Ejemplo SVG

Lee primero el marcado SVG. El navegador dibuja estos elementos directamente.

HTML inicial dentro de #demo

<svg viewBox="0 0 500 180">
  <ellipse id="elipse" cx="180" cy="85" rx="60" ry="20" fill="teal"/>
</svg>

JavaScript del ejemplo

const radios = [100, 40];
const elipse = document.querySelector("#elipse");
elipse.setAttribute("rx", radios[0]);
elipse.setAttribute("ry", radios[1]);
document.querySelector("#salida").textContent = "Ancho: " + (2 * radios[0]) + "\nAlto: " + (2 * radios[1]);
Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. cx,cy son el centro, no la esquina de una caja. Si rx=ry, se obtiene un círculo. La pareja de radios no es la misma que una pareja de anchura y altura.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
Edita js/svgellipse.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Prueba [60,60]: debes obtener un círculo de diámetro 120.
2. Relaciona cada número del código con una medida o propiedad visible. Cambia uno y comprueba tu predicción.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
