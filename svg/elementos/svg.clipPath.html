UN ARCHIVO · UN CONCEPTO

svg.clipPath

Recorta la región visible sin cambiar la geometría original.

Empieza por svg, rect, circle, line y text. defs, gradientes, recortes, máscaras y símbolos son ampliaciones.

Sintaxis

<clipPath id="recorte">
  <circle cx="200" cy="85" r="65"/>
</clipPath>

Qué significa cada medida. Un recorte controla qué parte del dibujo puede verse. No cambia los atributos width o height del rectángulo original.

Resultado esperado: Solo se ve la porción circular del rectángulo.

Ejemplo SVG

Lee primero el marcado SVG. El navegador dibuja estos elementos directamente.

HTML inicial dentro de #demo

<svg viewBox="0 0 500 180" role="img" aria-label="Ejemplo clipPath">
  <defs>
    <clipPath id="recorte">
      <circle cx="200" cy="85" r="65"/>
    </clipPath>
  </defs>
  <rect x="30" y="20" width="400" height="130" fill="teal" clip-path="url(#recorte)"/>
</svg>

Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. La región circular se define con centro (200,85) y radio 65. El rectángulo conserva su anchura 400 y altura 130, aunque se muestre solo su intersección con el recorte.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
Esta ficha se dibuja con SVG declarativo. Para modificarla edita el marcado HTML y recarga. El .js solo contiene comentarios; no necesitas cambiarlo.
Práctica
1. Reduce el radio del recorte y comprueba en el HTML que width y height del rectángulo no cambian.
2. Relaciona cada número del código con una medida o propiedad visible. Cambia uno y comprueba tu predicción.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
