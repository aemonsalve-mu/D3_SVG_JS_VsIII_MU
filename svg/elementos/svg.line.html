svg.line

Segmento entre dos puntos. Necesita stroke para verse.

Empieza por svg, rect, circle, line y text. defs, gradientes, recortes, máscaras y símbolos son ampliaciones.

Sintaxis

Antes de usar JavaScript con SVG

document.querySelector busca un nodo por su selector. setAttribute escribe un atributo y textContent muestra texto. Estudia primero la selección del DOM nativo y setAttribute. Los corchetes leen posiciones del array, empezando por 0.

const inicio = [30, 130];
const fin = [400, 30];
const linea = document.querySelector("#segmento");
linea.setAttribute("x1", inicio[0]);
linea.setAttribute("y1", inicio[1]);
linea.setAttribute("x2", fin[0]);
linea.setAttribute("y2", fin[1]);

Qué significa cada medida. Una línea se define con dos puntos: inicio=[x1,y1] y fin=[x2,y2]. Estos vectores contienen posiciones. No tiene atributos width y height como rect.

Resultado esperado: El segmento va de (30,130) a (400,30).

Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. En el ejemplo, inicio=[30,130] y fin=[400,30]. El cambio horizontal es 370 y el vertical −100. Su longitud no es ni 370 ni 100: se calcula a partir de ambos cambios.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
Edita js/svgline.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia fin a [400,130]: la línea debe quedar horizontal y medir 370 unidades.
2. Relaciona cada número del código con una medida o propiedad visible. Cambia uno y comprueba tu predicción.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
