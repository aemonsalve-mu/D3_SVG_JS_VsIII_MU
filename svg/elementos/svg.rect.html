UN ARCHIVO · UN CONCEPTO

svg.rect

Rectángulo definido por posición, anchura y altura.

Empieza por svg, rect, circle, line y text. defs, gradientes, recortes, máscaras y símbolos son ampliaciones.

Sintaxis

Antes de usar JavaScript con SVG

document.querySelector busca un nodo por su selector. setAttribute escribe un atributo y textContent muestra texto. Estudia primero la selección del DOM nativo y setAttribute. Los corchetes leen posiciones del array, empezando por 0.

const medida = [200, 90];
const rectangulo = document.querySelector("#rectangulo");
rectangulo.setAttribute("width", medida[0]);
rectangulo.setAttribute("height", medida[1]);

Qué significa cada medida. Un rectángulo necesita posición x,y y tamaño width,height. La pareja medida=[200,90] se interpreta como [ancho,alto]; medida[0] vale 200 y medida[1] vale 90.

Resultado esperado: El rectángulo pasa de 100 × 40 a 200 × 90; la esquina sigue en (30,30).

Ejemplo SVG

Lee primero el marcado SVG. El navegador dibuja estos elementos directamente.

HTML inicial dentro de #demo

<svg viewBox="0 0 500 180">
  <rect id="rectangulo" x="30" y="30" width="100" height="40" rx="10" fill="teal"/>
</svg>

JavaScript del ejemplo

const medida = [200, 90];
const rectangulo = document.querySelector("#rectangulo");
// La primera posición es el ancho; la segunda, el alto.
rectangulo.setAttribute("width", medida[0]);
rectangulo.setAttribute("height", medida[1]);
document.querySelector("#salida").textContent = "Ancho: " + medida[0] + "\nAlto: " + medida[1];
Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. El ejemplo escribe cada componente en un atributo distinto. x=30,y=30 sitúan la esquina superior izquierda; no se suman al ancho. rx redondea las esquinas, no cambia el tamaño total del rectángulo.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
Edita js/svgrect.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia medida a [300,50]. El ancho debe aumentar y la altura disminuir; la esquina superior izquierda debe permanecer en (30,30).
2. Relaciona cada número del código con una medida o propiedad visible. Cambia uno y comprueba tu predicción.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
