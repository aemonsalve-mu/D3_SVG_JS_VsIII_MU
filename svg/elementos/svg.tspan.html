UN ARCHIVO · UN CONCEPTO

svg.tspan

Fragmentos de texto para estilos o líneas adicionales.

Empieza por svg, rect, circle, line y text. defs, gradientes, recortes, máscaras y símbolos son ampliaciones.

Sintaxis

<tspan>Ventas</tspan>

Qué significa cada medida. tspan permite fragmentos dentro de text. x fija una posición y dy añade un desplazamiento relativo respecto a la posición de texto actual.

Resultado esperado: Dos líneas de texto.

Ejemplo SVG

Lee primero el marcado SVG. El navegador dibuja estos elementos directamente.

Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. El segundo fragmento usa x=40 y dy=35: vuelve a x=40 y baja 35 unidades. No significa que mida 35 de altura.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
Esta ficha se dibuja con SVG declarativo. Para modificarla edita el marcado HTML y recarga. El .js solo contiene comentarios; no necesitas cambiarlo.

Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
