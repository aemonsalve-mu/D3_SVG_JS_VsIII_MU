svg.circle

Círculo definido por centro y radio.

Empieza por svg, rect, circle, line y text. defs, gradientes, recortes, máscaras y símbolos son ampliaciones.

Sintaxis

Antes de usar JavaScript con SVG

document.querySelector busca un nodo por su selector. setAttribute escribe un atributo y textContent muestra texto. Estudia primero la selección del DOM nativo y setAttribute. Los corchetes leen posiciones del array, empezando por 0.

const radios = [15, 30, 45];
document.querySelector("#circulo-a").setAttribute("r", radios[0]);
document.querySelector("#circulo-b").setAttribute("r", radios[1]);
document.querySelector("#circulo-c").setAttribute("r", radios[2]);

Qué significa cada medida. Un círculo usa centro cx,cy y radio r. El vector radios=[15,30,45] contiene un radio por círculo, no [ancho,alto,profundidad].

Resultado esperado: Tres círculos con radios 15,30,45 y diámetros 30,60,90.

Ejemplo SVG

Lee primero el marcado SVG. El navegador dibuja estos elementos directamente.

JavaScript del ejemplo

const radios = [15, 30, 45];
// Un número del vector para cada círculo del HTML.
document.querySelector("#circulo-a").setAttribute("r", radios[0]);
document.querySelector("#circulo-b").setAttribute("r", radios[1]);
document.querySelector("#circulo-c").setAttribute("r", radios[2]);
document.querySelector("#salida").textContent = "Radios: " + radios + "\nDiámetros: 30,60,90";
Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. El diámetro es 2r y el área es πr². Los diámetros son 30,60,90; duplicar el radio multiplica el área por cuatro. Para representar cantidades mediante áreas, consulta scaleSqrt.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
Edita js/svgcircle.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia solo radios[1] a 45: el segundo círculo debe igualar el tamaño del tercero, conservando su centro.
2. Relaciona cada número del código con una medida o propiedad visible. Cambia uno y comprueba tu predicción.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
