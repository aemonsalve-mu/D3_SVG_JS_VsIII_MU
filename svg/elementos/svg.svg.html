svg.svg

Contenedor vectorial. viewBox define las coordenadas internas; CSS controla el tamaño mostrado.

Empieza por svg, rect, circle, line y text. defs, gradientes, recortes, máscaras y símbolos son ampliaciones.

Sintaxis

Antes de usar JavaScript con SVG

document.querySelector busca un nodo por su selector. setAttribute escribe un atributo y textContent muestra texto. Estudia primero la selección del DOM nativo y setAttribute. Los corchetes leen posiciones del array, empezando por 0.

const dimensiones = [500, 180];
const ancho = dimensiones[0];
const alto = dimensiones[1];
const lienzo = document.querySelector("#lienzo");
lienzo.setAttribute("viewBox", "0 0 " + ancho + " " + alto);

Qué significa cada medida. svg contiene el dibujo. [500,180] define aquí ancho y alto de su sistema interno; se escriben en viewBox después de los dos ceros de origen.

Resultado esperado: El sistema de coordenadas es de 500 × 180; el rectángulo mide 150 × 80.

Ejemplo SVG

Lee primero el marcado SVG. El navegador dibuja estos elementos directamente.

HTML inicial dentro de #demo

<svg id="lienzo" viewBox="0 0 500 180">

JavaScript del ejemplo

const dimensiones = [500, 180];
const ancho = dimensiones[0];
const alto = dimensiones[1];
const lienzo = document.querySelector("#lienzo");
lienzo.setAttribute("viewBox", "0 0 " + ancho + " " + alto);
document.querySelector("#salida").textContent = "Ancho interno: " + ancho + "\nAlto interno: " + alto;
Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. La anchura visible depende del CSS. Cambiar el vector a [1000,360] conserva la proporción del lienzo y cambia la relación entre unidades internas y pantalla.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
Edita js/svgsvg.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia dimensiones a [1000,360] y comprueba que el rectángulo no duplica automáticamente sus atributos width y height.
2. Relaciona cada número del código con una medida o propiedad visible. Cambia uno y comprueba tu predicción.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
