UN ARCHIVO · UN CONCEPTO

svg.linearGradient

Define un gradiente lineal reutilizable, habitualmente dentro de defs.

Empieza por svg, rect, circle, line y text. defs, gradientes, recortes, máscaras y símbolos son ampliaciones.

Sintaxis

<linearGradient id="grad">
  <stop offset="0%" stop-color="#ccebdc"/>
  <stop offset="100%" stop-color="teal"/>
</linearGradient>

Qué significa cada medida. El gradiente define una transición de pintura, no una figura visible por sí misma. El rectángulo que lo utiliza conserva sus dimensiones.

Resultado esperado: Rectángulo con gradiente.

Ejemplo SVG

Lee primero el marcado SVG. El navegador dibuja estos elementos directamente.

HTML inicial dentro de #demo

<svg viewBox="0 0 500 180" role="img" aria-label="Ejemplo linearGradient">

      <stop offset="100%" stop-color="teal"/>
    </linearGradient>
  </defs>
  <rect x="30" y="35" width="400" height="90" fill="url(#grad)"/>
</svg>

Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. Sin cambiar gradientUnits, las coordenadas del gradiente se expresan respecto a la caja del objeto. Los stop de 0% y 100% delimitan los colores a lo largo de esa dirección.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
