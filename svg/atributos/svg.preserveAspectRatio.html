UN ARCHIVO · UN CONCEPTO

svg.preserveAspectRatio

Controla alineación y ajuste al encajar viewBox en un viewport.

El HTML define el dibujo inicial. El .js solo cambia un atributo para comparar ambos resultados. Comenta esa instrucción y recarga para ver el estado original.

Sintaxis

Antes de usar el DOM del navegador

document representa esta página. document.querySelector("selector CSS") busca la primera coincidencia y devuelve el nodo del navegador, o null si no existe. No devuelve una selección D3. En este ejemplo el nodo ya está escrito en el HTML.

Si todavía no conoces esta instrucción, lee primero document.querySelector y querySelectorAll. La propiedad textContent escribe texto de un nodo; los métodos de esta ficha se llaman directamente sobre el nodo encontrado.

const figura = document.querySelector("#demo svg svg");
figura.setAttribute("preserveAspectRatio", "xMinYMin meet");

Qué significa cada medida. El SVG interior tiene un viewport de 400 × 150 y un viewBox de 100 × 100. Son dos parejas de dimensiones diferentes: tamaño de encaje y coordenadas internas.

Resultado esperado: El atributo preserveAspectRatio pasa a xMinYMin meet. Compara el resultado con el valor escrito en el HTML inicial.

Ejemplo SVG

Código JavaScript y resultado del ejemplo de svg.preserveAspectRatio.

HTML inicial dentro de #demo

<svg viewBox="0 0 500 180" role="img" aria-label="Ejemplo de preserveAspectRatio">
  <svg x="20" y="10" width="400" height="150" viewBox="0 0 100 100" preserveAspectRatio="xMidYMid meet">
    <rect width="100" height="100" fill="#d9eee2"/>
    <circle cx="50" cy="50" r="40" fill="teal"/>
  </svg>
</svg>

JavaScript del ejemplo

// La figura ya está en el HTML.
const figura = document.querySelector("#demo svg svg");
// Cambiamos únicamente el atributo estudiado.
figura.setAttribute("preserveAspectRatio", "xMinYMin meet");
Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. Con meet, el factor uniforme es el menor de 400/100 y 150/100: 1.5. El contenido ocupa 150 × 150 y sobran 250 unidades horizontales. xMid lo centra; xMin lo coloca al inicio. Con slice se usa el mayor factor, 4, y parte del contenido se recorta. Con none los factores x=4 e y=1.5 son distintos y el círculo se deforma.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
Edita js/svgpreserveaspectratio.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Compara xMinYMin meet, xMidYMid meet, xMidYMid slice y none. Conserva las medidas para aislar el efecto de cada opción.
2. Relaciona cada número del código con una medida o propiedad visible. Cambia uno y comprueba tu predicción.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
