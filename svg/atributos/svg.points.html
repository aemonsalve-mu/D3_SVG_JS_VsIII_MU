svg.points

Lista de pares x,y de polyline y polygon.

El HTML define el dibujo inicial. El .js solo cambia un atributo para comparar ambos resultados. Comenta esa instrucción y recarga para ver el estado original.

Sintaxis

Antes de usar el DOM del navegador

document representa esta página. document.querySelector("selector CSS") busca la primera coincidencia y devuelve el nodo del navegador, o null si no existe. No devuelve una selección D3. En este ejemplo el nodo ya está escrito en el HTML.

Si todavía no conoces esta instrucción, lee primero document.querySelector y querySelectorAll. La propiedad textContent escribe texto de un nodo; los métodos de esta ficha se llaman directamente sobre el nodo encontrado.

const puntos = [[30, 130], [130, 40], [260, 110], [400, 30]];
const puntoA = puntos[0];
const puntoB = puntos[1];
const puntoC = puntos[2];
const puntoD = puntos[3];
const texto = puntoA[0] + "," + puntoA[1] + " " +
  puntoB[0] + "," + puntoB[1] + " " +
  puntoC[0] + "," + puntoC[1] + " " +
  puntoD[0] + "," + puntoD[1];
document.querySelector("#demo polyline").setAttribute("points", texto);

Qué significa cada medida. points describe posiciones [x,y], no medidas [ancho,alto]. Cada pareja es un vértice; el orden de las parejas determina el recorrido.

Resultado esperado: La línea pasa por (30,130), (130,40), (260,110) y (400,30).

JavaScript del ejemplo

const puntos = [[30, 130], [130, 40], [260, 110], [400, 30]];
const puntoA = puntos[0];
const puntoB = puntos[1];
const puntoC = puntos[2];
const puntoD = puntos[3];
// Cada pareja se escribe como x,y; un espacio separa los puntos.
const texto = puntoA[0] + "," + puntoA[1] + " " +
  puntoB[0] + "," + puntoB[1] + " " +
  puntoC[0] + "," + puntoC[1] + " " +
  puntoD[0] + "," + puntoD[1];
document.querySelector("#demo polyline").setAttribute("points", texto);
document.querySelector("#salida").textContent = texto;
Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. Un array como [[30,130],[130,40],[260,110],[400,30]] debe convertirse en el texto de coordenadas que espera el atributo. En este ejemplo se accede a cada pareja con índices explícitos.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
Edita js/svgpoints.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Cambia solo puntos[1] de [130,40] a [130,100]: el segundo vértice debe bajar 60 unidades.
2. Relaciona cada número del código con una medida o propiedad visible. Cambia uno y comprueba tu predicción.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
