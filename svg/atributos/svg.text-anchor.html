UN ARCHIVO · UN CONCEPTO

svg.text-anchor

Alinea el texto respecto a su punto de anclaje: start, middle o end. Inicio y final dependen de la dirección de escritura.

El HTML define el dibujo inicial. El .js solo cambia un atributo para comparar ambos resultados. Comenta esa instrucción y recarga para ver el estado original.

Sintaxis

Antes de usar el DOM del navegador

document representa esta página. document.querySelector("selector CSS") busca la primera coincidencia y devuelve el nodo del navegador, o null si no existe. No devuelve una selección D3. En este ejemplo el nodo ya está escrito en el HTML.

Si todavía no conoces esta instrucción, lee primero document.querySelector y querySelectorAll. La propiedad textContent escribe texto de un nodo; los métodos de esta ficha se llaman directamente sobre el nodo encontrado.

const figura = document.querySelector("#demo text");
figura.setAttribute("text-anchor", "start");

Qué significa cada medida. text-anchor alinea el texto respecto a su punto de anclaje. start, middle y end no son posiciones adicionales ni tamaños de letra.

Resultado esperado: El atributo text-anchor pasa a start. Compara el resultado con el valor escrito en el HTML inicial.

Ejemplo SVG

Código JavaScript y resultado del ejemplo de svg.text-anchor.

HTML inicial dentro de #demo

<svg viewBox="0 0 500 180" role="img" aria-label="Ejemplo de text-anchor">
  <line x1="250" y1="15" x2="250" y2="160" stroke="gray"/>
  <text x="250" y="90" text-anchor="middle" font-size="24">Ventas</text>
</svg>

JavaScript del ejemplo

// La figura ya está en el HTML.
const figura = document.querySelector("#demo text");
// Cambiamos únicamente el atributo estudiado.
figura.setAttribute("text-anchor", "start");
Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. Con x=250 y escritura horizontal de izquierda a derecha, middle centra el texto en 250. start coloca su inicio allí. La longitud del texto depende de sus caracteres y su fuente.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
Edita js/svgtext-anchor.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Compara start, middle y end manteniendo x=250. La línea de referencia no debe moverse.
2. Relaciona cada número del código con una medida o propiedad visible. Cambia uno y comprueba tu predicción.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
