UN ARCHIVO · UN CONCEPTO

svg.transform

Compone traslación, rotación o escalado. El orden de transformaciones importa.

El HTML define el dibujo inicial. El .js solo cambia un atributo para comparar ambos resultados. Comenta esa instrucción y recarga para ver el estado original.

Sintaxis

Antes de usar el DOM del navegador

document representa esta página. document.querySelector("selector CSS") busca la primera coincidencia y devuelve el nodo del navegador, o null si no existe. No devuelve una selección D3. En este ejemplo el nodo ya está escrito en el HTML.

Si todavía no conoces esta instrucción, lee primero document.querySelector y querySelectorAll. La propiedad textContent escribe texto de un nodo; los métodos de esta ficha se llaman directamente sobre el nodo encontrado.

const desplazamiento = [130, 50];
const angulo = 30;
const figura = document.querySelector("#demo rect");
figura.setAttribute("transform", "translate(" + desplazamiento[0] + "," + desplazamiento[1] + ") rotate(" + angulo + ")");

Qué significa cada medida. translate(dx,dy) desplaza; rotate(ángulo) gira. El vector de desplazamiento [130,50] contiene dos posiciones relativas, no ancho y alto.

Resultado esperado: La figura aplica translate(130,50) rotate(30); mantiene su tamaño local de 140 × 60.

Ejemplo SVG

Código JavaScript y resultado del ejemplo de svg.transform.

HTML inicial dentro de #demo

<svg viewBox="0 0 500 180" role="img" aria-label="Ejemplo de transform">
  <rect x="0" y="0" width="140" height="60" fill="teal" transform="translate(100,50) rotate(15)"/>
</svg>

JavaScript del ejemplo

const desplazamiento = [130, 50];
const angulo = 30;
const figura = document.querySelector("#demo rect");
figura.setAttribute("transform", "translate(" + desplazamiento[0] + "," + desplazamiento[1] + ") rotate(" + angulo + ")");
Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. El ejemplo mantiene el rectángulo de 140 × 60 en sus coordenadas locales y aplica translate(130,50) rotate(30). Para puntos locales, esta composición gira primero y después traslada. Cambiar el orden produce otro resultado.
Conexión con los vectores. Los índices empiezan en 0. Antes de aplicar un array, define si sus posiciones contienen coordenadas, tamaños, radios o datos. width y height necesitan una longitud cada uno; una pareja completa no es un único ancho. Consulta vectores y dimensiones.
Edita js/svgtransform.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Compara translate(130,50) rotate(30) con rotate(30) translate(130,50).
2. Relaciona cada número del código con una medida o propiedad visible. Cambia uno y comprueba tu predicción.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
