SVGTextContentElement.getComputedTextLength

Mide el avance calculado del texto renderizado.

Paso siguiente al SVG básico. Empieza por getAttribute y setAttribute; las mediciones y matrices de coordenadas requieren más conocimientos.

Sintaxis

Antes de usar el DOM del navegador

document representa esta página. document.querySelector("selector CSS") busca la primera coincidencia y devuelve el nodo del navegador, o null si no existe. No devuelve una selección D3. En este ejemplo el nodo ya está escrito en el HTML.

Si todavía no conoces esta instrucción, lee primero document.querySelector y querySelectorAll. La propiedad textContent escribe texto de un nodo; los métodos de esta ficha se llaman directamente sobre el nodo encontrado.

const texto = document.querySelector("#texto-medido");
const longitud = texto.getComputedTextLength();

Qué significa cada medida. Mide el avance calculado del texto renderizado. Es una longitud tipográfica, no el número de caracteres ni el alto de la letra.

Resultado esperado: Una longitud que depende de la fuente renderizada.

Ejemplo SVG

Código JavaScript y resultado del ejemplo de SVGTextContentElement.getComputedTextLength.

HTML inicial dentro de #demo

<svg viewBox="0 0 500 180">
  <rect id="forma" x="40" y="30" width="180" height="90" fill="teal"/>
  <text id="texto-medido" x="30" y="160">Ventas Norte</text>
</svg>

JavaScript del ejemplo

const texto = document.querySelector("#texto-medido");
const longitud = texto.getComputedTextLength();
document.querySelector("#salida").textContent = "Longitud del texto: " + longitud;
Cómo leerlo, paso a paso
Cómo se interpreta el ejemplo. Cambiar font-size o el texto puede cambiar la longitud, aunque x e y permanezcan fijos. No deduzcas el ancho multiplicando un número fijo por la cantidad de letras.
El nodo y el resultado no son lo mismo. figura o texto es el nodo del DOM. El método puede devolver una longitud, un punto, una caja o una matriz; identifica ese tipo antes de leer sus propiedades. La ficha DOM nativo explica cómo se obtiene el nodo.
Edita js/svgtextcontentelementgetcomputedtextlength.js para cambiar el cálculo y recarga el HTML. El bloque de código mostrado es una copia para leer. Las etiquetas y los atributos iniciales se encuentran en el propio HTML.
Práctica
1. Escribe otra palabra y duplica font-size para comparar la longitud.
2. Relaciona cada número del código con una medida o propiedad visible. Cambia uno y comprueba tu predicción.
Cambia una sola medida cada vez. Predice primero el resultado, recarga y compáralo con tu predicción.
