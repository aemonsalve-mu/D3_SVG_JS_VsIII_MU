UN ARCHIVO · UN CONCEPTO

document.querySelector

Método del navegador que busca un selector CSS y devuelve el primer elemento coincidente del DOM. No pertenece a D3 y no necesita esa biblioteca.

Qué significa cada parte

document representa el documento HTML abierto. querySelector significa consultar por un selector: "#grupo-a" busca un id, ".alumno" una clase y "p" una etiqueta.

const elemento = document.querySelector("#grupo-a");

elemento es un nombre de variable elegido por nosotros. El resultado es el nodo del navegador; no es una selección D3. Si no hay coincidencia devuelve null, que significa ausencia de un elemento. No se deben leer propiedades de null.

elemento.querySelector("p") busca el primer párrafo dentro de ese elemento. No busca entre sus hermanos ni sus ancestros.

La variante querySelectorAll

document.querySelectorAll(".alumno") devuelve una lista llamada NodeList, con todas las coincidencias. Su propiedad length indica cuántos nodos hay. Si no hay coincidencias, la lista tiene longitud 0.

textContent es la propiedad DOM que lee o escribe texto literal de un nodo. No interpreta etiquetas HTML.

Comparación con D3: document.querySelector("#grupo-a") devuelve un nodo DOM; d3.select("#grupo-a") devuelve una selección D3. Para obtener su nodo se utiliza d3.select("#grupo-a").node(). Para leer texto con D3 se utiliza .text().

Ejemplo paso a paso

HTML inicial dentro de #demo

<div id="grupo-a">
  <p class="alumno">Ana</p>
  <p class="alumno">Luis</p>
</div>
<div id="grupo-b">
  <p class="alumno">Sara</p>
</div>

JavaScript del ejemplo

// document representa la página HTML que está abierta.
// querySelector devuelve el primer elemento coincidente, no una selección D3.
const primero = document.querySelector("#demo .alumno");

// Consultar un elemento concreto limita el lugar donde se buscan resultados.
const grupoB = document.querySelector("#grupo-b");
const alumnaB = grupoB.querySelector(".alumno");

// querySelectorAll devuelve una lista de todas las coincidencias.
const todos = document.querySelectorAll("#demo .alumno");
const salida = document.querySelector("#salida");

// textContent lee o escribe texto de un nodo DOM.
salida.textContent = "Primero: " + primero.textContent + "\n" +
  "Primera del grupo B: " + alumnaB.textContent + "\n" +
  "Total: " + todos.length;

Práctica
1. Cambia #demo .alumno por #grupo-b .alumno: solo debe encontrarse Sara.
2. Añade otro alumno al grupo A y observa el nuevo total.
3. Consulta document.querySelector("#no-existe") en la consola: devuelve null. No intentes leer su textContent.
