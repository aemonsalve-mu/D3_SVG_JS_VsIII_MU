CSV sin cabeceras: csvParseRows

Sin cabeceras, csvParse interpretaría la primera observación como nombres de columnas. Usa csvParseRows y asigna un esquema explícito.

1. Leer el archivo real

Lee el archivo ventas-sin-cabecera.csv. La ruta datos/ventas-sin-cabecera.csv se interpreta desde esta página HTML. El .js se carga al final del HTML y ejecuta la lectura automáticamente.

Para estas lecturas usa la guía del servidor HTTP local. Si abres el HTML por doble clic, el navegador puede impedir el acceso por URL; el selector de archivos del laboratorio sigue disponible.

Qué significa then

La lectura tarda un tiempo. then(function(datos) { ... }) ejecuta sus instrucciones cuando los datos han llegado. catch muestra un error. Las filas se consultan dentro de esa respuesta, no justo después de iniciar la petición.

JavaScript del archivo js/csv-sin-cabecera.js

// Lectura real de ventas-sin-cabecera.csv. El archivo está en la carpeta datos.
// Este script se ejecuta al cargar la página mediante HTTP.
d3.text("datos/ventas-sin-cabecera.csv").then(function(texto) {
  const datos = d3.csvParseRows(texto);
  d3.select("#salida-basica").text(
    "Filas del archivo: " + datos.length + "\n" +
    "Primera zona: " + datos[0][1]
  );
}).catch(function(error) {
  d3.select("#salida-basica").text("No se pudo cargar: " + error.message + ". Abre la carpeta mediante HTTP; consulta la guía.");
});

Resultado esperado: 4 filas del archivo sin cabecera; primera zona Norte.

Apoyo: interpretar texto ya escrito en el código

Este fragmento ilustrativo explica la estructura del formato. No realiza una lectura de archivo y no se ejecuta en esta página; el ejemplo principal de arriba sí lee el archivo externo.

const texto = "001,Norte,40\n002,Sur,100";
// Sin cabecera, cada fila es otro array.
const datos = d3.csvParseRows(texto);
d3.select("#salida-basica").text(

2. Cómo se convierten los bytes en datos

El selector usa await archivo.arrayBuffer(). Este código recibe ese buffer y devuelve un array. Puedes editarlo y volver a ejecutarlo.

3. Cargar por URL

Sirve la carpeta por HTTP y utiliza una ruta relativa o una URL con permiso CORS. Leer por URL no equivale a seleccionar un archivo del ordenador.

const texto = await d3.text("datos/ventas-sin-cabecera.csv");
const filas = d3.csvParseRows(texto,c=>({id:c[0],zona:c[1],ventas:Number(c[2]),objetivo:Number(c[3])}));

Si abres el HTML con file://, esta vía puede fallar. Utiliza el selector o consulta cómo iniciar un servidor local.
