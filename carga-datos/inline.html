Datos definidos directamente en JavaScript

Para ejemplos pequeños puedes usar un array en el propio script. No hay una petición de red ni lectura de archivo.

1. Comparación: datos escritos en el código

Comparación. Esta ficha no lee archivos externos.

No se lee ningún archivo ni se espera una petición. datos[0] es la primera fila y datos.length cuenta las filas.

Compara esta lista con los datos que llegan de un archivo CSV, JSON o Excel. Los corchetes encierran la lista; las llaves, cada fila; zona y ventas son propiedades.

Resultado esperado: 4 filas, primera zona Norte y venta 40.

JavaScript del archivo js/inline.js

// Un array es una lista; cada objeto describe una fila.
const datos = [
  {
    "zona": "Norte",
    "ventas": 40
  },
  {
    "zona": "Centro",
    "ventas": 70
  },
  {
    "zona": "Sur",
    "ventas": 100
  },
  {
    "zona": "Oeste",
    "ventas": 55
  }
];
d3.select("#salida-basica").text(
  "Filas: " + datos.length + "\n" +
  "Primera zona: " + datos[0].zona + "\n" +
  "Primera venta: " + datos[0].ventas
);

Sirve la carpeta por HTTP y utiliza una ruta relativa o una URL con permiso CORS. Leer por URL no
                equivale a seleccionar un archivo del ordenador.
