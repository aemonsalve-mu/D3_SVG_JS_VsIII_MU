CSV con fechas: UTC y tipos explícitos

Los archivos de texto no contienen objetos Date. Aquí las fechas YYYY-MM-DD se interpretan como UTC con utcParse para evitar diferencias por zona horaria.

JSON.stringify representa Date como texto ISO; consulta también el panel de tipos para comprobar que en memoria es un objeto Date.

1. Leer el archivo real

Lee el archivo ventas-fechas.csv. La ruta datos/ventas-fechas.csv se interpreta desde esta página HTML. El .js se carga al final del HTML y ejecuta la lectura automáticamente.

Primero leemos el CSV; después interpretamos su columna fecha con utcParse y mostramos la primera con utcFormat. Este ejemplo usa las fechas válidas de la muestra; el laboratorio incluye la validación estricta.

Para estas lecturas usa la guía del servidor HTTP local. Si abres el HTML por doble clic, el navegador puede impedir el acceso por URL; el selector de archivos del laboratorio sigue disponible.

Qué significa then

La lectura tarda un tiempo. then(function(datos) { ... }) ejecuta sus instrucciones cuando los datos han llegado. catch muestra un error. Las filas se consultan dentro de esa respuesta, no justo después de iniciar la petición.

JavaScript del archivo js/fechas.js

// Lectura real de ventas-fechas.csv. El archivo está en la carpeta datos.
// Este script se ejecuta al cargar la página mediante HTTP.
const leerFecha = d3.utcParse("%Y-%m-%d");
const mostrarFecha = d3.utcFormat("%d/%m/%Y");

d3.csv("datos/ventas-fechas.csv").then(function(datos) {
  const fecha = leerFecha(datos[0].fecha);
  d3.select("#salida-basica").text(
    "Filas: " + datos.length + "\n" +
    "Primera fecha UTC: " + mostrarFecha(fecha)
  );
}).catch(function(error) {
  d3.select("#salida-basica").text("No se pudo cargar: " + error.message + ". Abre la carpeta mediante HTTP; consulta la guía.");
});

Resultado esperado: 4 filas del CSV; primera fecha UTC 01/01/2026.

Apoyo: interpretar texto ya escrito en el código

Este fragmento ilustrativo explica la estructura del formato. No realiza una lectura de archivo y no se ejecuta en esta página; el ejemplo principal de arriba sí lee el archivo externo.

// UTC evita que la interpretación dependa de la zona horaria local.
const leerFecha = d3.utcParse("%Y-%m-%d");
const fecha = leerFecha("2026-01-02");
const mostrarFecha = d3.utcFormat("%d/%m/%Y");
d3.select("#salida-basica").text(
  "Fecha interpretada: " + mostrarFecha(fecha)
);

2. Cómo se convierten los bytes en datos

El selector usa await archivo.arrayBuffer(). Este código recibe ese buffer y devuelve un array. Puedes editarlo y volver a ejecutarlo.

3. Cargar por URL

Sirve la carpeta por HTTP y utiliza una ruta relativa o una URL con permiso CORS. Leer por URL no equivale a seleccionar un archivo del ordenador.

const leerFecha = d3.utcParse("%Y-%m-%d");
const filas = await d3.csv("datos/ventas-fechas.csv",d=>({...d,fecha:leerFecha(d.fecha),ventas:Number(d.ventas)}));

Si abres el HTML con file://, esta vía puede fallar. Utiliza el selector o consulta cómo iniciar un servidor local.
