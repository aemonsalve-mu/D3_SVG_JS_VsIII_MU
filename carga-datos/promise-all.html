Varios archivos con Promise.all

Promise.all permite esperar cargas independientes. El botón URL de esta ficha carga JSON y CSV y los empareja por id, no por posición.

El ejemplo incrustado contiene un archivo. Para ejecutar la carga simultánea de los dos archivos usa el botón URL con la carpeta servida por HTTP.

1. Leer el archivo real

Lee el archivo ventas.json. La ruta datos/ventas.json se interpreta desde esta página HTML. El .js se carga al final del HTML y ejecuta la lectura automáticamente.

Promise.all espera la lectura de ambos archivos y mantiene su orden en el resultado. No une sus filas automáticamente. El laboratorio añade el emparejamiento por id.

Para estas lecturas usa la guía del servidor HTTP local. Si abres el HTML por doble clic, el navegador puede impedir el acceso por URL; el selector de archivos del laboratorio sigue disponible.

Qué significa then

La lectura tarda un tiempo. then(function(datos) { ... }) ejecuta sus instrucciones cuando los datos han llegado. catch muestra un error. Las filas se consultan dentro de esa respuesta, no justo después de iniciar la petición.

JavaScript del archivo js/promise-all.js

// Lectura real de ventas.json. El archivo está en la carpeta datos.
// Este script se ejecuta al cargar la página mediante HTTP.
Promise.all([
  d3.json("datos/ventas.json"),
  d3.csv("datos/ventas.csv")
]).then(function(resultados) {
  // El orden del resultado coincide con el orden de las peticiones.
  const json = resultados[0];
  const csv = resultados[1];
  d3.select("#salida-basica").text(
    "Filas JSON: " + json.length + "\n" +
    "Filas CSV: " + csv.length
  );
}).catch(function(error) {
  d3.select("#salida-basica").text("No se pudo cargar: " + error.message + ". Abre la carpeta mediante HTTP; consulta la guía.");
});

Resultado esperado: 4 filas del JSON y 4 del CSV, leídos en dos peticiones.

2. Cómo se convierten los bytes en datos

El selector usa await archivo.arrayBuffer(). Este código recibe ese buffer y devuelve un array. Puedes editarlo y volver a ejecutarlo.

3. Cargar por URL

Sirve la carpeta por HTTP y utiliza una ruta relativa o una URL con permiso CORS. Leer por URL no equivale a seleccionar un archivo del ordenador.

const [a,b] = await Promise.all([d3.json("datos/ventas.json"),d3.csv("datos/ventas.csv")]);
const porId = new Map(b.map(d=>[d.id,d]));
const filas = a.map(d=>({...d,objetivo:Number(porId.get(d.id).objetivo)}));

Si abres el HTML con file://, esta vía puede fallar. Utiliza el selector o consulta cómo iniciar un servidor local.
