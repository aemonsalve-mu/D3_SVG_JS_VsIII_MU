HTML: leer una tabla

d3.html devuelve un fragmento de documento. Para extraer datos de una tabla hay que recorrer sus filas y celdas; no convierte automáticamente HTML a un dataset.

1. Leer el archivo real

Lee el archivo ventas-tabla.html. La ruta datos/ventas-tabla.html se interpreta desde esta página HTML. El .js se carga al final del HTML y ejecuta la lectura automáticamente.

d3.html devuelve el documento leído. Seleccionamos la primera fila y sus celdas con D3. nodes() devuelve un array de nodos; los índices 1 y 2 corresponden a zona y ventas, después del id.

Para estas lecturas usa la guía del servidor HTTP local. Si abres el HTML por doble clic, el navegador puede impedir el acceso por URL; el selector de archivos del laboratorio sigue disponible.

Qué significa then

La lectura tarda un tiempo. then(function(datos) { ... }) ejecuta sus instrucciones cuando los datos han llegado. catch muestra un error. Las filas se consultan dentro de esa respuesta, no justo después de iniciar la petición.

JavaScript del archivo js/html-tabla.js

// Lectura real de ventas-tabla.html. El archivo está en la carpeta datos.
// Este script se ejecuta al cargar la página mediante HTTP.
d3.html("datos/ventas-tabla.html").then(function(doc) {
  const celdas = d3.select(doc).select("#ventas tbody tr").selectAll("td").nodes();
  d3.select("#salida-basica").text(
    "Zona: " + d3.select(celdas[1]).text() + "\n" +
    "Venta: " + Number(d3.select(celdas[2]).text())
  );
}).catch(function(error) {
  d3.select("#salida-basica").text("No se pudo cargar: " + error.message + ". Abre la carpeta mediante HTTP; consulta la guía.");
});

Resultado esperado: Primera fila del archivo: zona Norte y venta 40.

Apoyo: interpretar texto ya escrito en el código

Este fragmento ilustrativo explica la estructura del formato. No realiza una lectura de archivo y no se ejecuta en esta página; el ejemplo principal de arriba sí lee el archivo externo.

// La pequeña tabla ya está escrita en el HTML.
const celdas = d3.select("#tabla-basica tbody tr").selectAll("td").nodes();
const zona = d3.select(celdas[0]).text();
const venta = Number(d3.select(celdas[1]).text());
d3.select("#salida-basica").text(
  "Zona: " + zona + "\n" +
  "Venta: " + venta
);
Ampliación opcional: selector de archivos, conversión, tabla y gráfico

El código avanzado puede usar métodos del navegador. Antes de leer querySelector, querySelectorAll o textContent, consulta la introducción al DOM nativo. No necesitas estos métodos para el recorrido inicial de D3.

2. Cómo se convierten los bytes en datos

El selector usa await archivo.arrayBuffer(). Este código recibe ese buffer y devuelve un array. Puedes editarlo y volver a ejecutarlo.

3. Cargar por URL

Sirve la carpeta por HTTP y utiliza una ruta relativa o una URL con permiso CORS. Leer por URL no equivale a seleccionar un archivo del ordenador.

const doc = await d3.html("datos/ventas-tabla.html");
const filas = Array.from(doc.querySelectorAll("#ventas tbody tr"));

Si abres el HTML con file://, esta vía puede fallar. Utiliza el selector o consulta cómo iniciar un servidor local.
