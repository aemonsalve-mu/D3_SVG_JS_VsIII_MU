Cómo cargar datos con D3

Un HTML independiente por formato o forma de carga. Cada ficha incluye el archivo, el código, la tabla de datos y un gráfico cuando hay ventas numéricas.

Aprender a leer archivos reales

El objetivo de estas fichas es abrir archivos externos, interpretar su formato y consultar sus datos con instrucciones sencillas. CSV, TSV, JSON y Excel forman parte del recorrido principal.

  1. CSV: leer ventas.csv con d3.csv, consultar filas y convertir una columna numérica.
  2. TSV: leer ventas.tsv con d3.tsv y comparar el separador.
  3. JSON: leer ventas.json con d3.json y acceder a sus objetos.
  4. Excel: leer directamente XLSX, XLS y ODS. D3 obtiene los bytes y SheetJS interpreta la hoja.
  5. Continuar con TXT, variantes CSV, XML, HTML, NDJSON, GeoJSON, recursos gráficos, binarios y GZIP. Cada formato tiene su archivo y su lector.

Inicia el servidor HTTP local y abre la ficha: su .js lee automáticamente el archivo de la carpeta datos. Revisa el resultado, modifica el archivo y recarga para comprobar el cambio.

Los fragmentos con texto incrustado son apoyo para interpretar el formato. Datos escritos en el código es una comparación: esa ficha no lee un archivo.

Selector local y laboratorio de datos

  1. Obtener bytes: selector de archivo, arrastrar y soltar o URL.
  2. Interpretar el formato: CSV, JSON, XML, Excel…
  3. Convertir tipos y validar campos.
  4. Mostrar la tabla y enlazar las filas al DOM o al SVG con D3.

El nombre del archivo es una pista; el contenido y su esquema determinan cómo leerlo. Number("") devuelve 0: valida vacíos antes de convertir. Conserva códigos como "001" como texto. Comprueba fechas y decimales.

Excel: biblioteca adicional

D3 no lee XLS, XLSX ni ODS por sí solo. Las fichas cargan SheetJS 0.20.3 desde su CDN oficial cuando lo necesitan. Requieren Internet. Para trabajar sin conexión, guarda xlsx.full.min.js en la carpeta vendor. El cargador intentará primero esa copia local.

El XLS incluido es BIFF2 binario auténtico, de una generación antigua de Excel. XLSX y ODS contienen una hoja Ventas. Los ejemplos no calculan fórmulas Excel: leen los datos guardados.

Cómo cargar por URL desde la carpeta

Si tienes Python, abre una terminal dentro de D3_SVG_por_archivos y ejecuta:

python -m http.server 8000 --bind 127.0.0.1

Abre http://127.0.0.1:8000/carga-datos/index.html. El servidor entrega archivos estáticos: no es una base de datos. El selector funciona sin servidor.

CORS lo decide el servidor de destino; no se resuelve con mode:"no-cors", porque la respuesta no puede leerse. En fetch comprueba response.ok. En d3.csv/json las respuestas HTTP fallidas producen errores.

Otros orígenes

SQL y bases de datos requieren normalmente una API que devuelva JSON o CSV. Google Sheets puede exponer un CSV con los permisos adecuados. Parquet y Arrow necesitan un lector específico antes de pasar los objetos a D3. PDF y Word requieren extracción de tablas o texto; no se leen con d3.csv. YAML necesita un parser adicional. Esta colección cubre los formatos y patrones listados con ejemplos; no presenta esos otros formatos como si fueran nativos de D3.

Práctica

Lee CSV, TSV, JSON y XLSX. Comprueba que contienen las mismas cuatro zonas; en el laboratorio, compara el total 265. Prueba autoType y explica qué pasa con 001. Carga el archivo de errores y explica por qué una venta ausente no debe convertirse en cero.
