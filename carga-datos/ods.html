OpenDocument ODS

D3 no incorpora un lector de Excel. Primero lee el archivo como ArrayBuffer; SheetJS interpreta el libro y sheet_to_json convierte una hoja en objetos.

Formato de hoja de cálculo de LibreOffice. SheetJS también puede leerlo; no es una función nativa de D3.

1. Leer el archivo real

Lee el archivo ventas.ods. La ruta datos/ventas.ods se interpreta desde esta página HTML. El .js se carga al final del HTML y ejecuta la lectura automáticamente.

Lectura principal del curso: OpenDocument ODS.

Este ejemplo lee el libro original, sin convertirlo previamente a CSV. D3 obtiene sus bytes con d3.buffer; SheetJS interpreta el libro con XLSX.read y transforma una hoja en filas con sheet_to_json.

cargarSheetJS() es la función auxiliar ya definida en carga.js para cargar la biblioteca, no un comando de D3. Busca primero una copia local y después su CDN. SheetNames[0] identifica la primera hoja. Los id de la muestra son texto; no se recalculan fórmulas.

Para estas lecturas usa la guía del servidor HTTP local. Si abres el HTML por doble clic, el navegador puede impedir el acceso por URL; el selector de archivos del laboratorio sigue disponible.

Qué significa then

La lectura tarda un tiempo. then(function(datos) { ... }) ejecuta sus instrucciones cuando los datos han llegado. catch muestra un error. Las filas se consultan dentro de esa respuesta, no justo después de iniciar la petición.

JavaScript del archivo js/ods.js

// Lectura real de ventas.ods. El archivo está en la carpeta datos.
// Este script se ejecuta al cargar la página mediante HTTP.
cargarSheetJS().then(function() {
  return d3.buffer("datos/ventas.ods");
}).then(function(buffer) {
  // SheetJS interpreta el libro; D3 solo ha leído los bytes.
  const libro = XLSX.read(buffer, {type: "array"});
  const primeraHoja = libro.SheetNames[0];
  const datos = XLSX.utils.sheet_to_json(libro.Sheets[primeraHoja]);
  d3.select("#salida-basica").text(
    "Filas: " + datos.length + "\n" +
    "Primera zona: " + datos[0].zona + "\n" +
    "Primera venta: " + datos[0].ventas
  );
}).catch(function(error) {
  d3.select("#salida-basica").text("No se pudo cargar: " + error.message + ". Abre la carpeta mediante HTTP; consulta la guía.");
});

Resultado esperado: 4 filas leídas del archivo; primera zona Norte y venta 40.

2. Cómo se convierten los bytes en datos

El selector usa await archivo.arrayBuffer(). Este código recibe ese buffer y devuelve un array. Puedes editarlo y volver a ejecutarlo.

3. Cargar por URL

Sirve la carpeta por HTTP y utiliza una ruta relativa o una URL con permiso CORS. Leer por URL no equivale a seleccionar un archivo del ordenador.

// Requiere SheetJS cargado además de D3.
const buffer = await d3.buffer("datos/ventas.ods");
const libro = XLSX.read(buffer,{type:"array",cellDates:true});
const filas = XLSX.utils.sheet_to_json(libro.Sheets["Ventas"],{defval:null});

Si abres el HTML con file://, esta vía puede fallar. Utiliza el selector o consulta cómo iniciar un servidor local.
