Validar vacíos y números antes del gráfico

No conviertas un vacío a cero sin comprobarlo. El ejemplo conserva cada fila y marca el problema; las ventas inválidas no se dibujan.

1. Leer el archivo real

Lee el archivo ventas-invalidas.csv. La ruta datos/ventas-invalidas.csv se interpreta desde esta página HTML. El .js se carga al final del HTML y ejecuta la lectura automáticamente.

El archivo contiene tres filas. Leemos la venta de la segunda, datos[1].ventas, y comprobamos el vacío antes de convertir. Cambia el índice para examinar otra fila.

Para estas lecturas usa la guía del servidor HTTP local. Si abres el HTML por doble clic, el navegador puede impedir el acceso por URL; el selector de archivos del laboratorio sigue disponible.

Qué significa then

La lectura tarda un tiempo. then(function(datos) { ... }) ejecuta sus instrucciones cuando los datos han llegado. catch muestra un error. Las filas se consultan dentro de esa respuesta, no justo después de iniciar la petición.

JavaScript del archivo js/validacion.js

// Lectura real de ventas-invalidas.csv. El archivo está en la carpeta datos.
// Este script se ejecuta al cargar la página mediante HTTP.
d3.csv("datos/ventas-invalidas.csv").then(function(datos) {
  // La segunda fila del archivo tiene la venta vacía.
  const valor = datos[1].ventas;
  if (valor.trim() === "") {
    d3.select("#salida-basica").text("Archivo leído: " + datos.length + " filas. Venta ausente en " + datos[1].zona + ": no convertir a cero.");
  } else {
    const venta = Number(valor);
    if (Number.isFinite(venta)) {
      d3.select("#salida-basica").text("Venta válida: " + venta);
    } else {
      d3.select("#salida-basica").text("Venta no numérica.");
    }
  }
}).catch(function(error) {
  d3.select("#salida-basica").text("No se pudo leer el archivo: " + error.message + ". Consulta la guía HTTP.");
});

Resultado esperado: 3 filas del archivo; la venta de Centro está ausente y no se transforma en cero.
