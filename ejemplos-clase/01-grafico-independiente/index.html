CASO 1 · UN GRÁFICO INDEPENDIENTE · 35 MINUTOS

¿Cómo evolucionan las ventas mensuales?

Un gráfico independiente debe poder entenderse por sí solo: pregunta, título, período, unidad, ejes y fuente. Aquí comparamos las ventas de enero a junio de una librería universitaria.

Guía para impartir la clase · Datos CSV · Datos JavaScript

Antes de programar

Objetivo: construir un gráfico de barras y explicar qué representa cada dimensión. Resultado inicial: 100, 120, 140, 170, 210 y 260 ejemplares; total del período, 1000.

Necesitas selectAll, data, scaleBand, scaleLinear y ejes. El código de la ficha los reúne sin añadir herramientas externas.

Leer un registro

const enero = datos[0];
const totalEnero = enero.tienda + enero.online;

datos es un array. Su primera posición es datos[0]. Cada objeto representa un mes; el punto accede a una propiedad con nombre, como tienda. d es el nombre que damos al registro recibido por una función; no es un comando de D3. return entrega el valor calculado.

El gráfico y sus cifras

Ventas mensuales: tienda + online
MesEjemplares

Fuente: datos sintéticos de clase. Período: enero-junio, sin año asignado. Unidad: ejemplares vendidos. Se suman dos canales distintos.

Cómo se construye, paso a paso

  1. El HTML contiene seis rectángulos, seis etiquetas y dos grupos para los ejes.
  2. dimensiones = [640, 360] proporciona ancho y alto. La base queda en 360 − 70 = 290. El área útil mide 540 × 250 unidades SVG.
  3. x reparte el intervalo [70, 610] entre los seis meses. x.bandwidth() devuelve el ancho de cada barra; padding(0.25) añade separación.
  4. y convierte [0, 300] en [290, 40]. Los números grandes quedan más arriba porque la coordenada y crece hacia abajo.
  5. Para enero, y(100) ≈ 206,67; su altura es 290 − 206,67 ≈ 83,33. La posición y y la altura son medidas distintas.
  6. data(datos) asigna un registro a cada rectángulo existente. Aquí no crea nuevos nodos.
  7. Las etiquetas usan las mismas escalas. El eje vertical parte de cero para que las longitudes se puedan comparar.

d3.sum(datos, función) suma los valores que devuelve la función para cada registro. datos.length es el número de registros; datos.length - 1 es el índice del último.

En la tabla, filas.select(".ventas") busca una celda dentro de cada fila y transmite a esa celda el dato de su fila, como en selection.select.

JavaScript del ejemplo

Este bloque reproduce el archivo de la subcarpeta js/. Primero se cargan D3 y ../datos/ventas.js, y después este código.

// 1. [ancho, alto] son medidas del SVG, no valores de ventas.
const dimensiones = [640, 360];
const ancho = dimensiones[0];
const alto = dimensiones[1];
const margenIzquierdo = 70;
const margenDerecho = 30;
const margenSuperior = 40;
const margenInferior = 70;
const base = alto - margenInferior;
d3.select("#grafico").attr("viewBox", "0 0 " + ancho + " " + alto);

// 2. Una escala para meses y otra para cantidades.
const x = d3.scaleBand();
x.domain(meses);
x.range([margenIzquierdo, ancho - margenDerecho]);
x.padding(0.25);
const y = d3.scaleLinear();
y.domain([0, 300]);
y.range([base, margenSuperior]);

// 3. El grupo del eje se coloca en su posición del dibujo.
d3.select("#eje-x").attr("transform", "translate(0," + base + ")");
d3.select("#eje-x").call(d3.axisBottom(x));
d3.select("#eje-y").attr("transform", "translate(" + margenIzquierdo + ",0)");
d3.select("#eje-y").call(d3.axisLeft(y).ticks(6));

// 4. Cada rectángulo recibe un mes. d es un objeto de datos.
const barras = d3.select("#barras").selectAll("rect").data(datos);
barras.attr("x", function(d) { return x(d.mes); });
barras.attr("y", function(d) { return y(d.tienda + d.online); });
barras.attr("width", x.bandwidth());
barras.attr("height", function(d) { return base - y(d.tienda + d.online); });

// 5. Las etiquetas usan los mismos datos y escalas.
const etiquetas = d3.select("#etiquetas").selectAll("text").data(datos);
etiquetas.attr("x", function(d) { return x(d.mes) + x.bandwidth() / 2; });
etiquetas.attr("y", function(d) { return y(d.tienda + d.online) - 10; });
etiquetas.text(function(d) { return d.tienda + d.online; });

// 6. La tabla ofrece una lectura exacta de las cifras.
const filas = d3.select("#tabla-datos").selectAll("tbody tr").data(datos);
filas.select(".mes").text(function(d) { return d.mes; });
filas.select(".ventas").text(function(d) { return d.tienda + d.online; });

// 7. d3.sum recorre los meses y suma la cantidad que devuelve la función.
const total = d3.sum(datos, function(d) { return d.tienda + d.online; });
const primero = datos[0].tienda + datos[0].online;
const ultimo = datos[datos.length - 1].tienda + datos[datos.length - 1].online;
d3.select("#resumen").text("Total del período: " + total + " ejemplares. Primer mes: " + primero + ". Último mes: " + ultimo + ".");

Práctica para el estudiante

  1. Antes de tocar el código, predice qué cambia si el lienzo pasa a [800, 360]. Después modifica dimensiones en js/grafico.js. Se ensancha el área útil, pero no cambian los datos.
  2. En ../datos/ventas.js, cambia las ventas online de junio de 130 a 150. Recarga. La última barra debe mostrar 280 y el total debe ser 1020.
  3. Cambia el dominio vertical a [0, 600]. Las barras deben medir la mitad en altura; las cifras no cambian. Explica por qué no conviene cambiar escalas entre gráficos que se comparan.
  4. Redacta una conclusión de una frase e indica qué no permite saber este gráfico: costes, beneficios o causas del crecimiento.

Criterio de logro: el gráfico se entiende sin explicación oral y el estudiante puede justificar los valores de x, y, width y height.
