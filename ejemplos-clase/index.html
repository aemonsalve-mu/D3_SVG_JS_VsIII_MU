Del gráfico independiente al dashboard

El objetivo es aprender a comunicar datos con gráficos comprensibles y construir un primer panel de seguimiento. Los tres casos utilizan los mismos datos sintéticos de una librería universitaria: seis meses, dos canales y sus objetivos de ventas.

Abre cada index.html directamente. D3 y los datos están incluidos; estos tres casos funcionan sin conexión. El CSV es una alternativa para practicar después la lectura de archivos.

Tres maneras de trabajar con los mismos datos

1. Gráfico independiente35 minutos. Responder una pregunta con barras, ejes, etiquetas y una tabla.2. Storytelling45 minutos. Relacionar tres gráficos: contexto, desglose y propuesta con límites.3. Dashboard55 minutos. Coordinar cuatro indicadores, dos gráficos, un filtro y una tabla.
Qué debe resolver cada caso
CasoPregunta principalHabilidad que se practica
Gráfico independiente¿Cómo evolucionan las ventas?Hacer un gráfico que se entienda por sí solo.
Storytelling¿Cómo se descompone el cambio y qué debemos investigar?Ordenar evidencia, distinguir denominadores y proponer una acción condicionada.
Dashboard¿Qué canal se acerca a sus objetivos?Explorar mediante filtros y mantener coherentes todas las vistas.

Una narración guía la lectura; un dashboard permite explorar. Se pueden combinar: el panel también puede contener mensajes que expliquen los hallazgos.

Versión extra del dashboard

Abrir el dashboard responsive: dos gráficos por fila. Panel compacto, una columna en móvil y formato A4 horizontal para imprimir.

Actividad individual de integración

Reproduce un dashboard sencillo: fuente y CSV con los mismos datos. Cuatro indicadores, dos gráficos, una tabla y tres frases de interpretación.

Qué conviene conocer antes

Para comenzar, reconoce etiquetas y atributos HTML/SVG, variables, arrays, objetos y funciones sencillas. Cada caso explica los conceptos adicionales que utiliza y enlaza con las fichas del temario.

  1. select, selectAll, data y attr.
  2. Vectores y dimensiones, scaleLinear y scaleBand.
  3. Ejes y, para el dashboard, eventos con on.

Las marcas están escritas en HTML para centrarnos en posiciones y medidas. No se usa join, código de componentes ni una librería de dashboards. Si amplías el número de meses, tendrás que adaptar los nodos o estudiar la creación de elementos.

Datos compartidos: una sola referencia para los tres casos

La unidad es ejemplares vendidos. Los datos no incluyen ingresos, costes ni beneficios. Cada objeto representa un mes; los canales se suman para obtener el total. Los objetivos son cantidades planificadas para el ejercicio.

// Datos sintéticos: ejemplares vendidos, no ingresos ni beneficios.
// Cada objeto entre llaves es un mes. Sus propiedades tienen nombre.
// datos[0] es enero; datos[0].tienda es el número 80.
const datos = [
  {mes: "Enero", tienda: 80, online: 20, objetivoTienda: 85, objetivoOnline: 25},
  {mes: "Febrero", tienda: 90, online: 30, objetivoTienda: 95, objetivoOnline: 35},
  {mes: "Marzo", tienda: 100, online: 40, objetivoTienda: 105, objetivoOnline: 45},
  {mes: "Abril", tienda: 110, online: 60, objetivoTienda: 115, objetivoOnline: 65},
  {mes: "Mayo", tienda: 120, online: 90, objetivoTienda: 125, objetivoOnline: 95},
  {mes: "Junio", tienda: 130, online: 130, objetivoTienda: 135, objetivoOnline: 115}
];

// El orden de este array fija el orden temporal del eje.
const meses = ["Enero", "Febrero", "Marzo", "Abril", "Mayo", "Junio"];

ventas.js es el archivo que se ejecuta. ventas.csv contiene los mismos datos de partida, pero los tres ejemplos no lo leen automáticamente. Al modificar el JavaScript, las tres páginas reflejan el cambio al recargarse. Si quieres mantener ambas versiones equivalentes, actualiza también el CSV.

Entregas mínimas del estudiante

  1. Un gráfico con pregunta, título, unidad, período, fuente y cifras verificadas.
  2. Una secuencia de tres gráficos y una explicación oral de noventa segundos que distinga evidencia y propuesta.
  3. Un dashboard con al menos tres indicadores, dos gráficos y un filtro que actualice también la tabla.

La prioridad es la exactitud: revisa datos, escalas y denominadores antes de añadir decoración o animaciones. Cada carpeta incluye una GUIA_CLASE.md con tiempos, preguntas, resultados esperados y evaluación.

Datos sintéticos de una librería universitaria. No representan una empresa real. Referencias: scaleBand, ejes y asignación de datos.
