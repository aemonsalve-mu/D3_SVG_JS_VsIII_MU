CASO 2 · STORYTELLING CON GRÁFICOS INDEPENDIENTES · 45 MINUTOS

Del crecimiento total a una decisión que debemos investigar

Storytelling significa ordenar la evidencia para que una audiencia comprenda un hallazgo y su relevancia. Cada gráfico debe sostenerse por sí mismo; la secuencia establece la relación entre ellos. Los titulares y gráficos se recalculan al cambiar ventas.js; los párrafos de cálculo explican las cifras iniciales.

Guía para impartir la clase · Datos CSV

Antes de programar

Pregunta de la responsable de la librería: ¿cómo están cambiando las ventas y qué canal conviene estudiar antes de planificar recursos?

Completa primero el caso 1. Aquí añadimos d3.line: un generador que convierte una secuencia de datos en el atributo d de un path. Sus funciones x e y indican dónde colocar cada punto. Los meses mantienen el orden de enero a junio; unir puntos no prueba qué sucedió entre las observaciones.

const porcentaje = d3.format(".0%");
const texto = porcentaje(0.5); // "50%"

d3.format devuelve una función que convierte números en texto. .0% muestra porcentajes sin decimales y .2% muestra dos. Se le pasa 0.5 para obtener 50%, no 50. El formato predeterminado de D3 usa punto decimal.

1 · QUÉ CAMBIÓ

Evolución del total mensual

La primera vista establece el contexto: misma unidad y misma población de ventas durante seis meses.

Fuente: datos sintéticos de la librería. Enero-junio. Total mensual = tienda + online. Escala vertical: 0–300 ejemplares.

Con los datos iniciales, el aumento absoluto es 260 − 100 = 160. El aumento relativo es 160 / 100 = 160 %. El último valor equivale al 260 % del primero: esa cifra no es el porcentaje de aumento.

2 · CÓMO SE DESCOMPONE EL CAMBIO

Comparación de canales

El total ocultaba dos trayectorias. Separar los canales permite ver qué cantidades componen cada mes.

Tienda: barra izquierdaOnline: barra derecha

Fuente: los mismos datos sintéticos. Enero-junio. Unidad: ejemplares. El orden y los colores de los canales se mantienen en la siguiente vista. Las dos primeras vistas comparten el intervalo vertical [0, 300].

Participación online = ventas online del mes / ventas totales del mes. En los datos iniciales, pasar del 20 % al 50 % supone 30 puntos porcentuales, no un aumento relativo del 30 %.

3 · QUÉ PARTE DEL AUMENTO CORRESPONDE A CADA CANAL

Aportación al aumento neto

La tercera vista compara diferencias entre junio y enero: con los datos iniciales, 50 unidades de tienda y 110 de online. No muestra ventas acumuladas del semestre. La participación online en el aumento es 110 / 160 = 68,75 %; su participación en las ventas de junio es 130 / 260 = 50 %. Son preguntas y denominadores distintos.

Fuente: los mismos datos sintéticos. Comparación junio menos enero. Unidad: aumento de ejemplares vendidos, con origen cero.

Propuesta para investigar

Revisar la capacidad de preparación y entrega del canal online antes de decidir si se reasignan recursos. Hacen falta datos de carga de trabajo, costes, márgenes, tiempos y satisfacción. El crecimiento de ventas por sí solo no demuestra rentabilidad ni necesidad de contratar.

La descomposición es aritmética. No demuestra que una campaña causara el aumento: no tenemos datos sobre campañas, estacionalidad ni un grupo de comparación.

Leer las dimensiones y el código

Las dos primeras vistas usan dimensiones = [640, 360], una base de 290 y las mismas escalas. Las barras de cada canal ocupan la mitad de x.bandwidth(). La segunda barra empieza después de la primera: x(d.mes) + anchoBarra.

La tercera vista usa otro vector, [640, 230], porque necesita solo dos filas. Su escala horizontal devuelve posiciones: el ancho de una barra es xAporte(d.aumento) - xAporte(0). Su dominio llega a 160; si pruebas aumentos mayores, amplíalo.

No hay funciones que construyan gráficos ocultando instrucciones. El archivo se lee por bloques: línea, comparación, diferencias y titulares. linea(datos) calcula la ruta; attr("d", ...) la asigna al path.

Ver todo el JavaScript del ejemplo
// 1. Las dos primeras vistas comparten dimensiones y escalas.
const dimensiones = [640, 360];
const ancho = dimensiones[0];
const alto = dimensiones[1];
const margenIzquierdo = 70;
const margenDerecho = 30;
const margenSuperior = 40;
const margenInferior = 70;
const base = alto - margenInferior;
d3.select("#tendencia").attr("viewBox", "0 0 " + ancho + " " + alto);
d3.select("#canales").attr("viewBox", "0 0 " + ancho + " " + alto);
const x = d3.scaleBand().domain(meses).range([margenIzquierdo, ancho - margenDerecho]).padding(0.25);
const y = d3.scaleLinear().domain([0, 300]).range([base, margenSuperior]);

// 2. Primer gráfico: puntos mensuales unidos en orden temporal.
d3.select("#tendencia-x").attr("transform", "translate(0," + base + ")").call(d3.axisBottom(x));
d3.select("#tendencia-y").attr("transform", "translate(" + margenIzquierdo + ",0)").call(d3.axisLeft(y).ticks(6));
const linea = d3.line();
linea.x(function(d) { return x(d.mes) + x.bandwidth() / 2; });
linea.y(function(d) { return y(d.tienda + d.online); });
d3.select("#linea-total").attr("d", linea(datos));
const puntos = d3.select("#puntos").selectAll("circle").data(datos);
puntos.attr("cx", function(d) { return x(d.mes) + x.bandwidth() / 2; });
puntos.attr("cy", function(d) { return y(d.tienda + d.online); });
const cifras = d3.select("#cifras-total").selectAll("text").data(datos);
cifras.attr("x", function(d) { return x(d.mes) + x.bandwidth() / 2; });
cifras.attr("y", function(d) { return y(d.tienda + d.online) - 12; });
cifras.text(function(d) { return d.tienda + d.online; });

// 3. Segundo gráfico: dos barras dentro de la banda de cada mes.
d3.select("#canales-x").attr("transform", "translate(0," + base + ")").call(d3.axisBottom(x));
d3.select("#canales-y").attr("transform", "translate(" + margenIzquierdo + ",0)").call(d3.axisLeft(y).ticks(6));
const anchoBarra = x.bandwidth() / 2;
const tienda = d3.select("#barras-tienda").selectAll("rect").data(datos);
tienda.attr("x", function(d) { return x(d.mes); });
tienda.attr("y", function(d) { return y(d.tienda); });
tienda.attr("width", anchoBarra);
tienda.attr("height", function(d) { return base - y(d.tienda); });
const online = d3.select("#barras-online").selectAll("rect").data(datos);
online.attr("x", function(d) { return x(d.mes) + anchoBarra; });
online.attr("y", function(d) { return y(d.online); });
online.attr("width", anchoBarra);
online.attr("height", function(d) { return base - y(d.online); });

// 4. Calculamos diferencias entre el último y el primer mes.
const primero = datos[0];
const ultimo = datos[datos.length - 1];
const totalInicial = primero.tienda + primero.online;
const totalFinal = ultimo.tienda + ultimo.online;
const aumentoTotal = totalFinal - totalInicial;
const aumentoTienda = ultimo.tienda - primero.tienda;
const aumentoOnline = ultimo.online - primero.online;
const aportes = [
  {canal: "Tienda", aumento: aumentoTienda},
  {canal: "Online", aumento: aumentoOnline}
];

// 5. Tercer gráfico: longitudes horizontales para las diferencias.
const dimensionesAporte = [640, 230];
const anchoAporte = dimensionesAporte[0];
const altoAporte = dimensionesAporte[1];
const baseAporte = altoAporte - 60;
d3.select("#aportaciones").attr("viewBox", "0 0 " + anchoAporte + " " + altoAporte);
const xAporte = d3.scaleLinear().domain([0, 160]).range([100, anchoAporte - 70]);
const yAporte = d3.scaleBand().domain(["Tienda", "Online"]).range([40, baseAporte]).padding(0.35);
d3.select("#aporte-x").attr("transform", "translate(0," + baseAporte + ")").call(d3.axisBottom(xAporte).tickValues([0, 40, 80, 120, 160]));
d3.select("#aporte-y").attr("transform", "translate(100,0)").call(d3.axisLeft(yAporte));
const barrasAporte = d3.select("#barras-aporte").selectAll("rect").data(aportes);
barrasAporte.attr("x", xAporte(0));
barrasAporte.attr("y", function(d) { return yAporte(d.canal); });
barrasAporte.attr("width", function(d) { return xAporte(d.aumento) - xAporte(0); });
barrasAporte.attr("height", yAporte.bandwidth());
const cifrasAporte = d3.select("#cifras-aporte").selectAll("text").data(aportes);
cifrasAporte.attr("x", function(d) { return xAporte(d.aumento) + 10; });
cifrasAporte.attr("y", function(d) { return yAporte(d.canal) + yAporte.bandwidth() / 2 + 5; });
cifrasAporte.text(function(d) { return "+" + d.aumento; });

// 6. Los titulares se calculan a partir de los datos, no de cifras copiadas.
const porcentaje = d3.format(".0%");
const porcentajeDetalle = d3.format(".2%");
d3.select("#mensaje-total").text("De " + totalInicial + " a " + totalFinal + " ejemplares: un aumento del " + porcentaje(aumentoTotal / totalInicial));
d3.select("#mensaje-canales").text("Online pasa del " + porcentaje(primero.online / totalInicial) + " al " + porcentaje(ultimo.online / totalFinal) + " de las ventas mensuales");
d3.select("#mensaje-aporte").text("Online aporta " + aumentoOnline + " de las " + aumentoTotal + " unidades del aumento neto: " + porcentajeDetalle(aumentoOnline / aumentoTotal));
d3.select("#dato-tienda").text("Tienda: " + primero.tienda + " → " + ultimo.tienda + " (aumento: " + aumentoTienda + ").");
d3.select("#dato-online").text("Online: " + primero.online + " → " + ultimo.online + " (aumento: " + aumentoOnline + ").");

// 7. Una tabla permite comprobar las dos series y su suma.
const filas = d3.select("#tabla-historia").selectAll("tbody tr").data(datos);
filas.select(".mes").text(function(d) { return d.mes; });
filas.select(".tienda-dato").text(function(d) { return d.tienda; });
filas.select(".online-dato").text(function(d) { return d.online; });
filas.select(".total-dato").text(function(d) { return d.tienda + d.online; });

Práctica para el estudiante

  1. Presenta la secuencia en noventa segundos. Debe contener pregunta, dos evidencias y una propuesta condicionada a más información.
  2. En ventas.js, cambia online de junio a 90. Comprueba: total final 220; aumento total 120; aumento online 70; aportación online al aumento 58,33 %. Explica cómo cambia el mensaje. Restaura el dato.
  3. Escribe tres frases que distingan aumento de ventas, participación de un canal y aportación al aumento.
  4. Propón un título que no atribuya causas que los datos no demuestran. Explica qué información recogerías antes de contratar o reasignar presupuesto.

Criterio de logro: las cifras de la narración se pueden verificar y cada gráfico responde a una pregunta distinta, sin cambiar la unidad ni esconder la escala.
